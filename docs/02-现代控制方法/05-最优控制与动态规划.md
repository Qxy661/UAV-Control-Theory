## 1. 最优控制概述

最优控制研究的是：**在满足系统动力学约束和各种约束条件下，找到使性能指标最优的控制策略**。

### 1.1 最优控制问题的一般形式

**目标**：最小化性能指标

$$J = \phi(x(t_f), t_f) + \int_{t_0}^{t_f} L(x(t), u(t), t) dt$$

**约束**：
- 系统动力学：$\dot{x} = f(x, u, t)$
- 初始条件：$x(t_0) = x_0$
- 终端约束：$x(t_f) \in \mathcal{X}_f$
- 输入约束：$u_{min} \leq u \leq u_{max}$

### 1.2 最优控制的分类

| 分类标准 | 类型 | 特点 |
|---------|------|------|
| 时间 | 连续/离散 | 连续用微分方程，离散用差分方程 |
| 终端 | 固定/自由/约束 | 终端状态的不同约束 |
| 性能指标 | 跟踪/调节/最短时间 | 不同优化目标 |
| 约束 | 无约束/有约束 | 约束处理方法不同 |

## 2. Pontryagin 最小值原理

### 2.1 Hamilton 函数

**Hamilton 函数**：

$$H(x, u, \lambda, t) = L(x, u, t) + \lambda^T f(x, u, t)$$

其中 $\lambda$ 为协态变量（costate）。

### 2.2 必要条件

**最优性的必要条件**：

$$\dot{x} = \frac{\partial H}{\partial \lambda} = f(x, u, t)$$

$$\dot{\lambda} = -\frac{\partial H}{\partial x}$$

$$\frac{\partial H}{\partial u} = 0 \quad \text{（无约束情况）}$$

**横截条件**：

$$\lambda(t_f) = \frac{\partial \phi}{\partial x}\bigg|_{t_f}$$

### 2.3 示例：最小能量控制

**问题**：最小化能量消耗

$$J = \int_0^{t_f} u^2(t) dt$$

**系统**：$\dot{x} = Ax + Bu$

**Hamilton 函数**：

$$H = u^2 + \lambda^T (Ax + Bu)$$

**最优控制**：

$$\frac{\partial H}{\partial u} = 2u + B^T \lambda = 0$$
$$u^* = -\frac{1}{2} B^T \lambda$$

**MATLAB 求解**：

```matlab
% 最小能量控制示例
% 系统：x_dot = Ax + Bu
% 性能指标：J = ∫ u² dt

A = [0 1; 0 0];
B = [0; 1];
x0 = [1; 0];  % 初始状态
xf = [0; 0];  % 终端状态
tf = 2;        % 终端时间

% 两点边值问题求解
% 使用 bvp4c
sol = bvp4c(@odefun, @bcfun, solinit);

function dydt = odefun(t, y)
    % y = [x; λ]
    x = y(1:2);
    lambda = y(3:4);
    u = -0.5 * B' * lambda;
    dxdt = A*x + B*u;
    dlambdadt = -A'*lambda;
    dydt = [dxdt; dlambdadt];
end

function res = bcfun(ya, yb)
    % 边界条件
    res = [ya(1:2) - x0;    % 初始条件
           yb(1:2) - xf];    % 终端条件
end
```

## 3. Hamilton-Jacobi-Bellman 方程

### 3.1 HJB 方程

**值函数**：

$$V(x, t) = \min_{u(\cdot)} \left\{ \phi(x(t_f), t_f) + \int_t^{t_f} L(x(\tau), u(\tau), \tau) d\tau \right\}$$

**HJB 方程**：

$$-\frac{\partial V}{\partial t} = \min_u \left\{ L(x, u, t) + \left(\frac{\partial V}{\partial x}\right)^T f(x, u, t) \right\}$$

### 3.2 最优控制律

**最优控制**：

$$u^* = \arg\min_u \left\{ L(x, u, t) + \left(\frac{\partial V}{\partial x}\right)^T f(x, u, t) \right\}$$

### 3.3 LQR 作为 HJB 的特例

**LQR 问题**：

$$J = \int_0^\infty (x^T Q x + u^T R u) dt$$

**HJB 方程**：

$$0 = \min_u \left\{ x^T Q x + u^T R u + \left(\frac{\partial V}{\partial x}\right)^T (Ax + Bu) \right\}$$

**解**：

$$V(x) = x^T P x$$

$$u^* = -R^{-1} B^T P x$$

**Riccati 方程**：

$$A^T P + PA - PBR^{-1}B^T P + Q = 0$$

## 4. 动态规划

### 4.1 动态规划原理

**Bellman 最优性原理**：最优策略具有"无论初始状态和初始决策如何，其余决策必须构成最优策略"的性质。

**Bellman 方程**：

$$V(x) = \min_u \left\{ L(x, u) + V(f(x, u)) \right\}$$

### 4.2 离散动态规划

```matlab
% 离散动态规划示例
% 网格化状态空间

% 参数
N = 20;  % 时间步数
M = 100; % 状态网格数

% 状态网格
x_grid = linspace(-5, 5, M);
u_grid = linspace(-1, 1, 50);

% 值函数初始化
V = zeros(M, N+1);

% 反向递推
for k = N:-1:1
    for i = 1:M
        x = x_grid(i);
        J_min = inf;
        for j = 1:length(u_grid)
            u = u_grid(j);
            x_next = x + 0.1 * (x^2 + u^2);  % 简化动力学
            J = x^2 + u^2 + interp1(x_grid, V(:,k+1), x_next);
            if J < J_min
                J_min = J;
            end
        end
        V(i, k) = J_min;
    end
end
```

## 5. 轨迹优化

### 5.1 直接法

**直接法**：将连续优化问题离散化为非线性规划（NLP）。

**直接打靶法**：

```matlab
% 直接打靶法
% 只优化控制变量，状态通过仿真得到

% 参数
N = 50;  % 时间步数
dt = 0.1;

% 优化变量：控制序列
u0 = zeros(N, 1);  % 初始猜测

% 目标函数
function J = objective(u, x0, A, B, Q, R, dt)
    x = x0;
    J = 0;
    for k = 1:length(u)
        J = J + (x'*Q*x + u(k)'*R*u(k)) * dt;
        x = x + (A*x + B*u(k)) * dt;
    end
    J = J + x'*Q*x;  % 终端代价
end

% 求解
options = optimoptions('fmincon', 'Algorithm', 'sqp');
u_opt = fmincon(@(u) objective(u, x0, A, B, Q, R, dt), ...
                u0, [], [], [], [], u_min, u_max, [], options);
```

**直接配点法**：

```matlab
% 直接配点法
% 同时优化状态和控制变量

% 优化变量：z = [x_1, u_1, x_2, u_2, ..., x_N, u_N]
z0 = zeros(2*N, 1);

% 动力学约束（配点约束）
function [c, ceq] = constraints(z, N, A, B, dt)
    c = [];
    ceq = [];
    for k = 1:N-1
        x_k = z(2*k-1);
        u_k = z(2*k);
        x_next = z(2*k+1);
        % 动力学约束
        ceq = [ceq; x_next - (x_k + (A*x_k + B*u_k)*dt)];
    end
end
```

### 5.2 间接法

**间接法**：基于 Pontryagin 最小值原理，求解两点边值问题。

```matlab
% 间接法：两点边值问题
% 使用 bvp4c 求解

function sol = indirect_method(x0, xf, tf, A, B, Q, R)
    % 协态变量初值猜测
    lambda0 = [1; 1];

    % bvp4c 求解
    solinit = bvpinit(linspace(0, tf, 10), [x0; lambda0]);
    sol = bvp4c(@(t, y) odefun(t, y, A, B, Q, R), ...
                @(ya, yb) bcfun(ya, yb, x0, xf), solinit);
end

function dydt = odefun(t, y, A, B, Q, R)
    x = y(1:2);
    lambda = y(3:4);
    u = -R \ B' * lambda;  % 最优控制
    dxdt = A*x + B*u;
    dlambdadt = -Q*x - A'*lambda;
    dydt = [dxdt; dlambdadt];
end

function res = bcfun(ya, yb, x0, xf)
    res = [ya(1:2) - x0;    % 初始条件
           yb(1:2) - xf];    % 终端条件
end
```

## 6. 最优控制在无人机中的应用

### 6.1 最小时间轨迹优化

**问题**：从起点到终点的最短时间飞行

$$J = t_f$$

**约束**：
- 最大速度：$|v| \leq v_{max}$
- 最大加速度：$|a| \leq a_{max}$
- 避障约束：$||p - p_{obs}|| \geq d_{safe}$

```matlab
% 最小时间轨迹优化
% 使用 CasADi
import casadi.*

% 优化变量
opti = casadi.Opti();
N = 100;
X = opti.variable(4, N+1);  % [x, y, vx, vy]
U = opti.variable(2, N);    % [ax, ay]
T = opti.variable();        % 总时间

% 目标：最小化时间
opti.minimize(T);

% 动力学约束
dt = T / N;
for k = 1:N
    opti.subject_to(X(:,k+1) == X(:,k) + dt * [X(3:4,k); U(:,k)]);
end

% 约束
opti.subject_to(-v_max <= X(3:4,:) <= v_max);
opti.subject_to(-a_max <= U <= a_max);

% 边界条件
opti.subject_to(X(:,1) == x0);
opti.subject_to(X(:,N+1) == xf);
opti.subject_to(T >= 0);

% 求解
opti.solver('ipopt');
sol = opti.solve();
```

### 6.2 能量最优轨迹

```matlab
% 能量最优轨迹

for k = 1:N
```

## 7. 最优控制与 MPC 的关系

### 7.1 有限时域 vs 无限时域

| 方面 | 最优控制 | MPC |
|------|---------|-----|
| 时域 | 有限/无限 | 有限（滚动） |
| 求解 | 离线 | 在线 |
| 反馈 | 开环 | 闭环（滚动优化） |
| 约束 | 可处理 | 显式处理 |
| 计算 | 一次求解 | 每步求解 |

### 7.2 MPC 作为近似最优控制

```
MPC 与最优控制的关系：

最优控制：min J_0→∞
├── 无限时域，理论最优
├── 计算困难，不实用
└── 开环控制

MPC：min J_k→k+N
├── 有限时域，次优
├── 在线计算，实用
├── 反馈校正
└── 滚动优化近似无限时域
```

## 思考题

1. Pontryagin 最小值原理和 HJB 方程有什么关系？各有什么优缺点？
2. 直接法和间接法在轨迹优化中各有什么优缺点？
3. 为什么 LQR 可以看作 HJB 方程的特例？
4. 动态规划的"维数灾难"问题如何解决？
5. 在四旋翼轨迹优化中，如何处理避障约束？

<details>
<summary>参考答案</summary>

1. 关系：两者都是最优控制的必要条件。PMP 是一阶必要条件，HJB 是充分条件。PMP 优点：处理约束方便，可验证最优性。HJB 优点：可得到反馈控制律。缺点：PMP 需要解两点边值问题，HJB 需要解偏微分方程。

2. 直接法优点：不需要协态变量，容易处理约束，可使用成熟的 NLP 求解器。缺点：离散化误差。间接法优点：精度高，可验证最优性。缺点：需要好的协态初值猜测，处理约束困难。

3. LQR 是 HJB 特例：(1) 系统线性：f = Ax + Bu；(2) 代价二次：L = x'Qx + u'Ru；(3) 无限时域，稳态解；(4) 值函数二次：V = x'Px；(5) 代入 HJB 得 Riccati 方程。

4. 维数灾难解决方法：(1) 函数逼近（神经网络、多项式）；(2) 网格简化（自适应网格）；(3) 分解方法（动态规划分解）；(4) 近似动态规划；(5) 强化学习方法。

5. 避障约束处理：(1) 将障碍物表示为不等式约束；(2) 使用距离函数：d(p, p_obs) >= d_safe；(3) 可用碰撞锥方法线性化；(4) 使用混合整数规划处理复杂障碍物；(5) 分层方法：规划层避障，控制层跟踪。

</details>
