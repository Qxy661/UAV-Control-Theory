## 1. 动态面控制概述

动态面控制（Dynamic Surface Control, DSC）是反步法的改进版本，通过引入低通滤波器避免解析求导，解决反步法中的"项爆炸"问题。

### 1.1 反步法的问题

```
┌─────────────────────────────────────────────────┐
│              反步法的"项爆炸"问题                  │
├─────────────────────────────────────────────────┤
│                                                 │
│  反步法需要计算虚拟控制的导数：                    │
│  α₁ = f(x₁)                                    │
│  α₂ = g(x₁, x₂, α₁, dα₁/dt)                   │
│  α₃ = h(x₁, x₂, x₃, α₁, α₂, dα₁/dt, dα₂/dt)  │
│                                                 │
│  问题：                                          │
│  ├── 随着阶数增加，表达式急剧膨胀                 │
│  ├── 需要精确的模型信息                          │
│  ├── 计算量大                                    │
│  └── 实现困难                                    │
│                                                 │
└─────────────────────────────────────────────────┘
```

### 1.2 DSC 的解决思路

**DSC 的核心思想**：用低通滤波器代替解析求导

```
┌─────────────────────────────────────────────────┐
│              DSC 核心思想                         │
├─────────────────────────────────────────────────┤
│                                                 │
│  反步法：α_k = f(x, α_{k-1}, dα_{k-1}/dt)      │
│                                                 │
│  DSC：引入低通滤波器                              │
│  τ_k ẏ_k + y_k = α_{k-1}                       │
│  y_k 代替 α_{k-1} 的解析导数                     │
│                                                 │
│  优点：                                          │
│  ├── 避免解析求导                                │
│  ├── 设计更简单                                  │
│  ├── 对模型不确定性更鲁棒                        │
│  └── 计算量小                                    │
│                                                 │
└─────────────────────────────────────────────────┘
```

## 2. DSC 设计步骤

### 2.1 基本步骤

**第一步**：与反步法相同，设计虚拟控制 α₁

$$\alpha_1 = -\frac{1}{g_1}(f_1 + c_1 x_1)$$

**第二步**：低通滤波

$$\tau_2 \dot{y}_2 + y_2 = \alpha_1, \quad y_2(0) = \alpha_1(0)$$

**第三步**：设计虚拟控制 α₂（用 y₂ 代替 α₁）

$$\alpha_2 = -\frac{1}{g_2}(f_2 + c_2(x_2 - y_2))$$

**重复**：直到得到实际控制 u

### 2.2 MATLAB 实现

```matlab
function u = DSC_controller(x, params)
    % 动态面控制器
    % x: 状态向量
    % params: 参数结构体

    c1 = params.c1;
    c2 = params.c2;
    tau2 = params.tau2;  % 滤波时间常数

    % 第一步：虚拟控制 α₁
    f1 = x(1)^2;
    g1 = 1;
    alpha1 = -(f1 + c1*x(1)) / g1;

    % 低通滤波
    % y2 的更新（离散实现）
    y2 = (tau2 * y2_prev + dt * alpha1) / (tau2 + dt);

    % 第二步：虚拟控制 α₂
    z2 = x(2) - y2;
    f2 = sin(x(1)) + x(2);
    g2 = 1;
    alpha2 = -(f2 + c2*z2) / g2;

    % 最终控制
    u = alpha2;
end
```

## 3. DSC 与反步法对比

### 3.1 设计复杂度对比

| 方面 | 反步法 | DSC |
|------|--------|-----|
| 求导 | 需要解析求导 | 低通滤波代替 |
| 表达式 | 项爆炸 | 简洁 |
| 计算量 | 大 | 小 |
| 模型依赖 | 高 | 低 |
| 实现难度 | 高 | 低 |

### 3.2 稳定性对比

```
稳定性分析对比：

反步法：
├── 每步构造 Lyapunov 函数
├── 严格保证稳定性
└── 需要精确模型

DSC：
├── 考虑滤波误差
├── 稳定性分析更复杂
├── 需要选择合适的滤波时间常数
└── 对模型误差更鲁棒
```

## 4. DSC 在四旋翼中的应用

### 4.1 姿态 DSC 控制

```matlab
function tau = attitude_DSC(phi, theta, psi, p, q, r, ...
    phi_ref, theta_ref, psi_ref, y_prev, params)
    % 四旋翼姿态 DSC 控制

    c = params.c;
    tau_f = params.tau_f;  % 滤波时间常数
    dt = params.dt;

    % 误差
    e_phi = phi - phi_ref;
    e_theta = theta - theta_ref;
    e_psi = psi - psi_ref;

    % 虚拟控制（期望角速率）
    alpha_p = -c * e_phi;
    alpha_q = -c * e_theta;
    alpha_r = -c * e_psi;

    % 低通滤波
    y_p = (tau_f * y_prev(1) + dt * alpha_p) / (tau_f + dt);
    y_q = (tau_f * y_prev(2) + dt * alpha_q) / (tau_f + dt);
    y_r = (tau_f * y_prev(3) + dt * alpha_r) / (tau_f + dt);

    % 角速率误差
    e_p = p - y_p;
    e_q = q - y_q;
    e_r = r - y_r;

    % 控制力矩
    tau_phi = -c * e_p;
    tau_theta = -c * e_q;
    tau_psi = -c * e_r;

    tau = [tau_phi; tau_theta; tau_psi];
    y_new = [y_p; y_q; y_r];
end
```

## 5. DSC 的改进

### 5.1 自适应 DSC

**问题**：系统参数未知

**解决**：引入参数估计

```matlab
function [u, theta_hat] = adaptive_DSC(x, theta_hat, params)
    % 自适应 DSC
    gamma = params.gamma;
    c = params.c;
    tau = params.tau;

    % 虚拟控制（含参数估计）
    alpha = -(f_hat(x, theta_hat) + c*x(1));

    % 低通滤波
    y = low_pass_filter(alpha, tau);

    % 参数更新律
    theta_hat_dot = -gamma * x(1) * df_dtheta(x, theta_hat);
    theta_hat = theta_hat + theta_hat_dot * dt;

    % 控制律
    u = -(f_hat(x, theta_hat) + c*(x(2) - y));
end
```

### 5.2 鲁棒 DSC

**问题**：存在不确定性和扰动

**解决**：增加鲁棒项

```matlab
function u = robust_DSC(x, params)
    % 鲁棒 DSC
    c = params.c;
    tau = params.tau;
    rho = params.rho;  % 扰动界

    % 虚拟控制
    alpha = -(f(x) + c*x(1));

    % 低通滤波
    y = low_pass_filter(alpha, tau);

    % 标称控制
    u_nominal = -(f(x) + c*(x(2) - y));

    % 鲁棒项
    s = x(2) - y;
    u_robust = -rho * sign(s);

    % 总控制
    u = u_nominal + u_robust;
end
```

## 思考题

1. DSC 的滤波时间常数 $\tau$ 如何选择？过大和过小会有什么问题？
2. DSC 和反步法的稳定性分析有什么区别？
3. 自适应 DSC 如何处理参数不确定性？
4. DSC 在四旋翼控制中相比反步法有什么具体优势？
5. DSC 和滑模控制结合有什么好处？

<details>
<summary>参考答案</summary>

1. τ 选择：(1) τ 过大：滤波器带宽低，跟踪延迟大，性能下降；(2) τ 过小：滤波效果差，接近反步法；(3) 经验：τ ≈ 1/(5-10)ω_c，ω_c 为期望带宽；(4) 需要权衡滤波效果和跟踪延迟。

2. 稳定性分析：(1) 反步法：每步严格 Lyapunov 分析，稳定性明确；(2) DSC：需考虑滤波误差，Lyapunov 函数包含滤波误差项；(3) DSC 稳定性分析更复杂，但结论类似。

3. 处理参数不确定性：(1) 引入参数估计 θ̂；(2) 设计自适应律更新 θ̂；(3) 在虚拟控制和控制律中使用 θ̂；(4) 保证参数估计误差收敛。

4. DSC 优势：(1) 避免姿态角导数的复杂表达式；(2) 不需要精确的耦合项模型；(3) 实现简单，计算量小；(4) 对模型误差更鲁棒。

5. DSC+滑模：(1) DSC 避免项爆炸；(2) 滑模提供鲁棒性；(3) 结合两者优点；(4) 例如：在滑模面设计中使用 DSC 思想。

</details>
