## 1. 非线性观测器概述

非线性观测器用于估计非线性系统的状态，当状态不能直接测量时尤为重要。

### 1.1 观测器的作用

```
┌─────────────────────────────────────────────────┐
│              观测器的作用                          │
├─────────────────────────────────────────────────┤
│                                                 │
│  1. 状态估计：无法直接测量的状态                   │
│     ├── 角速度（IMU 测量但有噪声）                │
│     ├── 位置（GPS 更新慢）                       │
│     └── 扰动（不可测量）                          │
│                                                 │
│  2. 滤波：降低测量噪声                            │
│                                                 │
│  3. 故障检测：比较估计值和测量值                   │
│                                                 │
│  4. 软传感器：估计难以测量的量                     │
│                                                 │
└─────────────────────────────────────────────────┘
```

### 1.2 线性 vs 非线性观测器

| 方面 | 线性观测器 | 非线性观测器 |
|------|-----------|-------------|
| 适用系统 | 线性系统 | 非线性系统 |
| 设计方法 | 极点配置 | Lyapunov 方法 |
| 收敛性 | 全局 | 局部或全局 |
| 计算量 | 低 | 中-高 |

## 2. 扩张状态观测器（ESO）

### 2.1 ESO 原理

**系统**：$\dot{x} = f(x, u) + d$

**ESO**：将扰动 $d$ 扩展为新状态

$$\begin{cases}
\dot{z}_1 = z_2 - \beta_1 (z_1 - y) \\
\dot{z}_2 = -\beta_2 (z_1 - y) + b_0 u
\end{cases}$$

### 2.2 线性 ESO (LESO)

```matlab
function [z1, z2] = LESO(y, u, z1_prev, z2_prev, b0, wo, dt)
    % 线性扩张状态观测器
    e = z1_prev - y;

    z1_dot = z2_prev - 2*wo*e;
    z2_dot = -wo^2*e + b0*u;

    z1 = z1_prev + z1_dot * dt;
    z2 = z2_prev + z2_dot * dt;
end
```

### 2.3 非线性 ESO

```matlab
function [z1, z2] = nonlinear_ESO(y, u, z1_prev, z2_prev, b0, beta, alpha, delta, dt)
    % 非线性扩张状态观测器
    e = z1_prev - y;

    z1_dot = z2_prev - beta(1) * fal(e, alpha(1), delta);
    z2_dot = -beta(2) * fal(e, alpha(2), delta) + b0 * u;

    z1 = z1_prev + z1_dot * dt;
    z2 = z2_prev + z2_dot * dt;
end

function y = fal(e, alpha, delta)
    % 非线性函数
    if abs(e) > delta
        y = abs(e)^alpha * sign(e);
    else
        y = e / delta^(1-alpha);
    end
end
```

### 2.4 ESO 收敛性分析

ESO 的核心优势在于其收敛速度可由单一参数 $\omega_o$（观测器带宽）直接调控。下面对线性 ESO (LESO) 进行严格的收敛性分析。

**误差定义**：

$$e_1 = z_1 - x_1, \quad e_2 = z_2 - x_2$$

其中 $x_1$ 为系统状态，$x_2 = f(x,u,d)$ 为总扰动（扩展状态）。

**误差动态方程**：

$$\begin{cases}
\dot{e}_1 = \dot{z}_1 - \dot{x}_1 = (z_2 - 2\omega_o e_1) - x_2 = e_2 - 2\omega_o e_1 \\
\dot{e}_2 = \dot{z}_2 - \dot{x}_2 = (-\omega_o^2 e_1 + b_0 u) - (b_0 u + \dot{f}) = -\omega_o^2 e_1 - \dot{f}
\end{cases}$$

其中 $\dot{f}$ 为总扰动的时间导数。在分析收敛性时，假设 $\dot{f}$ 有界（即扰动变化率有限）。

**矩阵形式**：

$$\dot{\mathbf{e}} = A_o \mathbf{e} + B_o \dot{f}$$

$$A_o = \begin{bmatrix} -2\omega_o & 1 \\ -\omega_o^2 & 0 \end{bmatrix}, \quad B_o = \begin{bmatrix} 0 \\ -1 \end{bmatrix}$$

**特征多项式与极点配置**：

$$\det(sI - A_o) = s^2 + 2\omega_o s + \omega_o^2 = (s + \omega_o)^2$$

LESO 的两个极点均位于 $s = -\omega_o$，为**重极点**配置。这意味着：

- 误差动态是临界阻尼的，无超调
- 收敛速度完全由 $\omega_o$ 决定
- $\omega_o$ 越大，收敛越快

**收敛速率分析**：

齐次解（忽略 $\dot{f}$）的形式为：

$$e_1(t) = (C_1 + C_2 t) e^{-\omega_o t}, \quad e_2(t) = (C_3 + C_4 t) e^{-\omega_o t}$$

误差以 $e^{-\omega_o t}$ 的速率指数衰减。时间常数为 $\tau_o = 1/\omega_o$，约 $3\tau_o$（即 $3/\omega_o$）时间后误差衰减到 5% 以内。

当 $\dot{f} \neq 0$ 时，稳态误差有界：

$$|e_{1,ss}| \leq \frac{|\dot{f}|}{\omega_o^2}, \quad |e_{2,ss}| \leq \frac{2|\dot{f}|}{\omega_o}$$

$\omega_o$ 越大，稳态误差越小。

**调参规则**：

$$\boxed{\omega_o > 5 \cdot \omega_c}$$

其中 $\omega_c$ 为控制器带宽。该规则保证观测器的收敛速度至少是控制器响应速度的 5 倍，使观测器对控制器而言"足够快"。

```
┌─────────────────────────────────────────────────────────┐
│              LESO 调参指南                               │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  步骤 1：确定控制器带宽 ω_c                              │
│         （由期望闭环响应速度决定）                         │
│                                                         │
│  步骤 2：设定 ω_o = 5ω_c ~ 10ω_c                        │
│         观测器带宽越大，跟踪越快                          │
│         但噪声放大也越严重                               │
│                                                         │
│  步骤 3：离散化实现时注意采样率                            │
│         采样频率 fs > 10 * ω_o / (2π)                    │
│         否则离散化误差导致观测器不稳定                     │
│                                                         │
│  步骤 4：实际调试                                        │
│         从较小 ω_o 开始，逐步增大                         │
│         观察估计值是否出现高频振荡                        │
│         振荡说明 ω_o 过大或采样率不足                      │
│                                                         │
│  典型值（四旋翼姿态控制）：                               │
│         ω_c ≈ 5~15 rad/s                                │
│         ω_o ≈ 30~100 rad/s                              │
│         采样率 ≥ 400 Hz                                  │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

**MATLAB 验证示例**：

```matlab
% ESO 收敛性验证
wo = 50;          % 观测器带宽
wc = 10;          % 控制器带宽
disp(['ω_o/ω_c = ', num2str(wo/wc)]);  % 应 ≥ 5

% 特征多项式验证
Ao = [-2*wo, 1; -wo^2, 0];
poles = eig(Ao);
disp(['ESO 极点: ', num2str(poles')]);  % 应为 [-wo, -wo]

% 收敛时间估计
tau_o = 1/wo;
settling_time = 3 * tau_o;  % 5% 误差带
disp(['估计收敛时间: ', num2str(settling_time), ' s']);
```

## 3. 滑模观测器

### 3.1 滑模观测器原理

**系统**：$\dot{x} = Ax + Bu + d$

**滑模观测器**：

$$\dot{\hat{x}} = A\hat{x} + Bu + L(y - C\hat{x}) + \eta \cdot \text{sign}(y - C\hat{x})$$

### 3.2 MATLAB 实现

```matlab
function x_hat = sliding_mode_observer(y, u, x_hat_prev, A, B, C, L, eta, dt)
    % 滑模观测器
    e = y - C * x_hat_prev;

    x_hat_dot = A * x_hat_prev + B * u + L * e + eta * sign(e);
    x_hat = x_hat_prev + x_hat_dot * dt;
end
```

### 3.3 超螺旋滑模观测器

```matlab
function [x_hat, z] = super_twisting_observer(y, u, x_hat_prev, z_prev, ...
    A, B, C, L, k1, k2, dt)
    % 超螺旋滑模观测器
    e = y - C * x_hat_prev;

    x_hat_dot = A * x_hat_prev + B * u + L * e + z_prev;
    z_dot = k1 * sign(e) + k2 * e;

    x_hat = x_hat_prev + x_hat_dot * dt;
    z = z_prev + z_dot * dt;
end
```

## 4. 高增益观测器

### 4.1 高增益观测器原理

**系统**：$\dot{x} = f(x, u)$

**高增益观测器**：

$$\dot{\hat{x}} = f(\hat{x}, u) + H(\epsilon)(y - C\hat{x})$$

其中 $H(\epsilon) = \text{diag}(1/\epsilon, 1/\epsilon^2, ..., 1/\epsilon^n)$

### 4.2 MATLAB 实现

```matlab
function x_hat = high_gain_observer(y, u, x_hat_prev, epsilon, dt)
    % 高增益观测器
    n = length(x_hat_prev);
    H = diag(1 ./ epsilon.^(1:n));

    e = y - C * x_hat_prev;
    x_hat_dot = f(x_hat_prev, u) + H * e;
    x_hat = x_hat_prev + x_hat_dot * dt;
end
```

### 4.3 高增益观测器的特点

```
高增益观测器特点：

优点：
├── 设计简单
├── 对模型不确定性鲁棒
└── 可处理一类非线性系统

缺点：
├── 对测量噪声敏感（高增益放大噪声）
├── 可能出现峰值现象
└── 需要选择合适的 ε
```

## 5. 扰动观测器

### 5.1 扰动观测器原理

**系统**：$\dot{x} = f(x) + g(x)u + d$

**扰动观测器**：估计总扰动 $d$

$$\dot{\hat{d}} = -L\hat{d} + L(f(x) + g(x)u - \dot{x})$$

### 5.2 MATLAB 实现

```matlab
function d_hat = disturbance_observer(x_dot, x, u, d_hat_prev, L, f, g, dt)
    % 扰动观测器
    d_hat_dot = -L * d_hat_prev + L * (f(x) + g(x) * u - x_dot);
    d_hat = d_hat_prev + d_hat_dot * dt;
end
```

## 思考题

1. ESO 和传统状态观测器有什么本质区别？
2. 滑模观测器的"滑模"体现在哪里？
3. 高增益观测器的"峰值现象"是什么？如何解决？
4. 扰动观测器和 ESO 在估计扰动方面有什么异同？
5. 在四旋翼控制中，如何选择合适的观测器？

<details>
<summary>参考答案</summary>

1. 本质区别：(1) 传统观测器估计已定义的状态；(2) ESO 将扰动扩展为新状态，同时估计状态和扰动；(3) ESO 不需要精确的扰动模型；(4) ESO 可与 ADRC 结合实现主动抗扰。

2. 滑模体现：(1) 观测器包含 sign 函数，具有切换特性；(2) 误差在有限时间内收敛到滑模面；(3) 在滑模面上，观测器对匹配不确定性具有不变性；(4) 可用于故障检测。

3. 峰值现象：(1) 高增益观测器初始阶段输出很大；(2) 由于高增益放大初始误差；(3) 解决方法：使用饱和函数、限制初始输出、使用切换观测器。

4. 异同：(1) 相同：都估计总扰动；(2) 不同：ESO 是状态观测器，DOB 是输入观测器；(3) ESO 估计状态+扰动，DOB 只估计扰动；(4) ESO 不需要 x_dot，DOB 需要。

5. 选择考虑：(1) 传感器特性：噪声水平、更新率；(2) 系统特性：非线性程度、不确定性大小；(3) 计算资源：嵌入式平台限制；(4) 实践：常用 EKF 或 ESO。

</details>
