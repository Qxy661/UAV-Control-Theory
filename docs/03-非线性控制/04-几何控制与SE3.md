## 1. 几何控制概述

几何控制是基于李群（Lie Group）理论的控制方法，特别适用于在旋转流形 SO(3) 和刚体运动流形 SE(3) 上的控制问题。

### 1.1 为什么需要几何控制？

```
┌─────────────────────────────────────────────────┐
│              欧拉角的局限性                        │
├─────────────────────────────────────────────────┤
│                                                 │
│  欧拉角（Roll-Pitch-Yaw）的问题：                 │
│  ├── 万向节锁（Gimbal Lock）：θ=90°时奇异        │
│  ├── 不连续：角度从180°跳到-180°                 │
│  ├── 非唯一：同一姿态有多种表示                    │
│  └── 求导复杂：角速度与欧拉角速率关系复杂          │
│                                                 │
│  几何控制的优势：                                 │
│  ├── 在SO(3)上直接设计，避免奇异                  │
│  ├── 全局定义，无不连续性                         │
│  ├── 直接使用旋转矩阵或四元数                     │
│  └── 理论优美，稳定性分析清晰                     │
│                                                 │
└─────────────────────────────────────────────────┘
```

### 1.2 SE(3) 与 SO(3) 基础

**SO(3)：特殊正交群（旋转矩阵）**

$$SO(3) = \{R \in \mathbb{R}^{3 \times 3} | R^T R = I, \det(R) = 1\}$$

**SE(3)：特殊欧氏群（刚体运动）**

$$SE(3) = \left\{ \begin{bmatrix} R & p \\ 0 & 1 \end{bmatrix} | R \in SO(3), p \in \mathbb{R}^3 \right\}$$

**四元数**：

$$q = [q_0, q_1, q_2, q_3]^T, \quad q_0^2 + q_1^2 + q_2^2 + q_3^2 = 1$$

## 2. SO(3) 上的控制

### 2.1 误差函数定义

**姿态误差**（旋转矩阵）：

$$e_R = \frac{1}{2} (R_d^T R - R^T R_d)^\vee$$

其中 $R_d$ 为期望旋转矩阵，$(\cdot)^\vee$ 为向量运算。

**姿态误差**（四元数）：

$$e_q = q_d^{-1} \otimes q$$

### 2.2 Lyapunov 函数设计

**姿态误差 Lyapunov 函数**：

$$V = \frac{1}{2} \text{tr}(I - R_d^T R)$$

**导数**：

$$\dot{V} = -e_R^T \omega$$

### 2.3 控制律设计

**角速度控制律**：

$$\omega_d = -k_R e_R$$

**力矩控制律**：

$$\tau = -k_R e_R - k_\omega e_\omega + \omega \times J\omega$$

其中 $e_\omega = \omega - R^T R_d \omega_d$

### 2.4 MATLAB 实现

```matlab
function tau = geometric_attitude_control(R, omega, R_d, omega_d, params)
    % 几何姿态控制
    % R: 当前旋转矩阵
    % omega: 当前角速度
    % R_d: 期望旋转矩阵
    % omega_d: 期望角速度
    % params: 参数

    kR = params.kR;
    kW = params.kW;
    J = params.J;  % 转动惯量矩阵

    % 姿态误差
    eR = 0.5 * veemap(R_d' * R - R' * R_d);

    % 角速度误差
    eW = omega - R' * R_d * omega_d;

    % 力矩控制律
    tau = -kR * eR - kW * eW + cross(omega, J * omega);
end

function v = veemap(M)
    % 反对称矩阵到向量
    v = [M(3,2) - M(2,3);
         M(1,3) - M(3,1);
         M(2,1) - M(1,2)] / 2;
end
```

## 3. SE(3) 上的跟踪控制

### 3.1 SE(3) 跟踪问题

**目标**：跟踪期望的位姿轨迹 $(R_d(t), p_d(t))$

**误差定义**：

$$e_R = \frac{1}{2} (R_d^T R - R^T R_d)^\vee$$
$$e_p = p - p_d$$

### 3.2 SE(3) 控制律

**位置控制律**：

$$f = -k_p e_p - k_v e_v + m g e_3$$

**姿态控制律**：

$$\tau = -k_R e_R - k_\omega e_\omega + \omega \times J\omega$$

### 3.3 MATLAB 实现

```matlab
function [f, tau] = SE3_tracking_control(R, omega, p, v, ...
    R_d, omega_d, p_d, v_d, params)
    % SE(3) 跟踪控制

    kp = params.kp;
    kv = params.kv;
    kR = params.kR;
    kW = params.kW;
    m = params.m;
    g = params.g;
    J = params.J;

    % 位置误差
    eP = p - p_d;
    eV = v - v_d;

    % 姿态误差
    eR = 0.5 * veemap(R_d' * R - R' * R_d);
    eW = omega - R' * R_d * omega_d;

    % 位置控制（推力）
    f = -kp * eP - kv * eV + m * g * [0; 0; 1];

    % 姿态控制（力矩）
    tau = -kR * eR - kW * eW + cross(omega, J * omega);
end
```

## 4. 四元数几何控制

### 4.1 四元数误差

**四元数乘法**：

$$q_1 \otimes q_2 = [q_{10}q_{20} - q_{1v}^T q_{2v}; q_{10}q_{2v} + q_{20}q_{1v} + q_{1v} \times q_{2v}]$$

**四元数误差**：

$$e_q = q_d^* \otimes q$$

### 4.2 四元数控制律

```matlab
function tau = quaternion_attitude_control(q, omega, q_d, omega_d, params)
    % 四元数姿态控制

    kR = params.kR;
    kW = params.kW;
    J = params.J;

    % 四元数误差
    q_d_conj = [q_d(1); -q_d(2:4)];
    e_q = quatmultiply(q_d_conj, q);

    % 姿态误差（使用向量部分）
    eR = e_q(2:4);

    % 角速度误差
    R = quat2rotm(q);
    R_d = quat2rotm(q_d);
    eW = omega - R' * R_d * omega_d;

    % 控制律
    tau = -kR * eR - kW * eW + cross(omega, J * omega);
end

function q = quatmultiply(q1, q2)
    % 四元数乘法
    q = [q1(1)*q2(1) - q1(2)*q2(2) - q1(3)*q2(3) - q1(4)*q2(4);
         q1(1)*q2(2) + q1(2)*q2(1) + q1(3)*q2(4) - q1(4)*q2(3);
         q1(1)*q2(3) - q1(2)*q2(4) + q1(3)*q2(1) + q1(4)*q2(2);
         q1(1)*q2(4) + q1(2)*q2(3) - q1(3)*q2(2) + q1(4)*q2(1)];
end
```

## 5. 几何控制在无人机中的应用

### 5.1 四旋翼 SE(3) 控制

```
┌─────────────────────────────────────────────────┐
│           四旋翼 SE(3) 控制结构                   │
├─────────────────────────────────────────────────┤
│                                                 │
│  位置参考 ──→ [位置控制器] ──→ 推力大小 + 期望姿态 │
│                                        │        │
│                                        ↓        │
│              [姿态控制器] ──→ 力矩               │
│                    │                            │
│                    ↓                            │
│              [电机混控] ──→ 电机控制量             │
│                                                 │
│  关键：位置控制器输出推力大小和期望姿态            │
│        姿态控制器跟踪期望姿态                     │
│                                                 │
└─────────────────────────────────────────────────┘
```

### 5.2 完整实现

```matlab
function [f_cmd, tau_cmd] = quadrotor_SE3_control(state, ref, params)
    % 四旋翼 SE(3) 完整控制

    % 提取状态
    R = state.R;       % 旋转矩阵
    omega = state.omega; % 角速度
    p = state.p;       % 位置
    v = state.v;       % 速度

    % 提取参考
    R_d = ref.R_d;     % 期望旋转矩阵
    omega_d = ref.omega_d;
    p_d = ref.p_d;
    v_d = ref.v_d;

    % 位置控制
    eP = p - p_d;
    eV = v - v_d;
    f_vec = -params.kp * eP - params.kv * eV ...
            + params.m * params.g * [0; 0; 1];
    f_cmd = norm(f_vec);

    % 期望姿态（从推力向量计算）
    z_b = f_vec / norm(f_vec);
    x_c = [cos(ref.yaw_d); sin(ref.yaw_d); 0];
    y_b = cross(z_b, x_c) / norm(cross(z_b, x_c));
    x_b = cross(y_b, z_b);
    R_d = [x_b, y_b, z_b];

    % 姿态控制
    eR = 0.5 * veemap(R_d' * R - R' * R_d);
    eW = omega - R' * R_d * omega_d;
    tau_cmd = -params.kR * eR - params.kW * eW ...
              + cross(omega, params.J * omega);
end
```

## 6. 几何控制与其他方法对比

| 方法 | 奇异性 | 鲁棒性 | 计算复杂度 | 适用范围 |
|------|--------|--------|-----------|---------|
| 几何控制 | 无 | 中 | 中 | 刚体姿态 |
| 欧拉角 PID | 有 | 弱 | 低 | 小角度 |
| 四元数控制 | 无 | 中 | 低 | 姿态控制 |
| 反步法 | 取决于参数化 | 中 | 中 | 严格反馈系统 |

## 思考题

1. 为什么几何控制能避免万向节锁问题？
2. SO(3) 上的误差函数如何定义？有哪些选择？
3. 几何控制的 Lyapunov 稳定性分析有什么特点？
4. 在四旋翼控制中，如何从位置控制器的输出计算期望姿态？
5. 几何控制对模型不确定性有什么处理方法？

<details>
<summary>参考答案</summary>

1. 避免万向节锁：(1) 几何控制直接在 SO(3) 上设计，不使用欧拉角；(2) 旋转矩阵/四元数全局定义，无奇异点；(3) 误差函数在 SO(3) 上光滑连续；(4) 不存在角度表示的奇异性。

2. 误差函数选择：(1) 矩阵误差：eR = (R_d'R - R'R_d)^∨/2；(2) 四元数误差：e_q = q_d* ⊗ q；(3) 对数映射：e = log(R_d'R)；(4) 选择考虑：连续性、可微性、物理意义。

3. 稳定性分析特点：(1) Lyapunov 函数在 SO(3) 上定义；(2) 误差函数满足正定性；(3) 导数可证明负定；(4) 全局稳定性分析（避免局部线性化）。

4. 计算期望姿态：(1) 位置控制器输出推力向量 f；(2) 期望 z 轴：z_b = f/||f||；(3) 期望 x 轴：根据偏航角和 z_b 计算；(4) 期望 y 轴：y_b = z_b × x_b；(5) 期望旋转矩阵：R_d = [x_b, y_b, z_b]。

5. 处理不确定性：(1) 增大控制增益提高鲁棒性；(2) 加入鲁棒项（如滑模项）；(3) 自适应估计不确定性；(4) 结合扰动观测器。

</details>
