## 1. 滑模控制概述

滑模控制（Sliding Mode Control, SMC）是一种变结构控制方法，通过设计切换面使系统状态在有限时间内到达并保持在滑模面上。

### 1.1 核心思想

```
┌─────────────────────────────────────────────────┐
│              滑模控制核心思想                      │
├─────────────────────────────────────────────────┤
│                                                 │
│  1. 设计滑模面 s(x) = 0                          │
│                                                 │
│  2. 设计控制律使状态到达滑模面（到达阶段）          │
│                                                 │
│  3. 状态在滑模面上运动（滑动阶段）                  │
│     ├── 滑模面上系统动态由滑模面决定               │
│     ├── 对匹配不确定性具有不变性                   │
│     └── 鲁棒性强                                 │
│                                                 │
│  控制律通常包含切换项：                            │
│  u = u_eq + u_sw                                 │
│  u_eq: 等效控制（保持在滑模面）                    │
│  u_sw: 切换控制（到达滑模面）                      │
│                                                 │
└─────────────────────────────────────────────────┘
```

### 1.2 滑模控制的优缺点

| 优点 | 缺点 |
|------|------|
| 对匹配不确定性鲁棒 | 切换导致抖振 |
| 设计简单 | 需要不确定性界 |
| 响应快速 | 高频切换损坏执行器 |
| 可处理非线性 | 对未匹配不确定性敏感 |

## 2. 滑模面设计

### 2.1 线性滑模面

**一阶系统**：

$$s = e = x - x_d$$

**二阶系统**：

$$s = \dot{e} + \lambda e$$

其中 $e = x - x_d$，$\lambda > 0$。

**一般形式**：

$$s = \left(\frac{d}{dt} + \lambda\right)^{n-1} e$$

### 2.2 非线性滑模面

**终端滑模面**：

$$s = \dot{e} + \beta |e|^\alpha \text{sign}(e)$$

其中 $0 < \alpha < 1$，$\beta > 0$。

**优势**：有限时间收敛

### 2.3 积分滑模面

$$s = e + \lambda \int_0^t e(\tau) d\tau$$

**优势**：消除到达阶段，提高鲁棒性

### 2.4 MATLAB 实现

```matlab
function s = sliding_surface(e, edot, lambda, type)
    % 计算滑模面
    % e: 误差
    % edot: 误差导数
    % lambda: 滑模面参数
    % type: 滑模面类型

    switch type
        case 'linear'
            s = edot + lambda * e;
        case 'terminal'
            beta = 1;
            alpha = 0.5;
            s = edot + beta * abs(e)^alpha * sign(e);
        case 'integral'
            s = e + lambda * integral_e;
    end
end
```

## 3. 滑模控制律设计

### 3.1 等效控制

**系统**：$\dot{x} = f(x) + g(x)u + d$

**等效控制**（保持在滑模面上）：

$$u_{eq} = -g(x)^{-1} f(x)$$

**推导**：$\dot{s} = 0$ 时的控制

### 3.2 切换控制

**切换控制**（到达滑模面）：

$$u_{sw} = -\eta \text{sign}(s)$$

其中 $\eta > 0$ 为切换增益。

**到达条件**：

$$s \dot{s} < -\eta |s|$$

### 3.3 完整控制律

$$u = u_{eq} + u_{sw} = -g(x)^{-1} f(x) - \eta \text{sign}(s)$$

### 3.4 MATLAB 实现

```matlab
function u = sliding_mode_control(x, xd, xd_dot, params)
    % 滑模控制器
    % x: 状态
    % xd: 期望状态
    % params: 参数

    lambda = params.lambda;
    eta = params.eta;

    % 误差
    e = x - xd;
    edot = x_dot - xd_dot;

    % 滑模面
    s = edot + lambda * e;

    % 等效控制
    f = nonlinear_f(x);
    g = input_gain(x);
    u_eq = -inv(g) * f;

    % 切换控制
    u_sw = -eta * sign(s);

    % 总控制
    u = u_eq + u_sw;
end
```

## 4. 抖振问题与解决

### 4.1 抖振产生原因

```
┌─────────────────────────────────────────────────┐
│              抖振产生原因                         │
├─────────────────────────────────────────────────┤
│                                                 │
│  1. 切换函数 sign(s) 的不连续性                   │
│                                                 │
│  2. 系统惯性和延迟                               │
│                                                 │
│  3. 离散时间实现的采样效应                        │
│                                                 │
│  4. 不确定性的估计误差                            │
│                                                 │
│  结果：控制量高频切换，损坏执行器                  │
│                                                 │
└─────────────────────────────────────────────────┘
```

### 4.2 抖振消除方法

**方法一：边界层法**

$$u_{sw} = \begin{cases}
-\eta \text{sign}(s), & |s| > \phi \\
-\eta \frac{s}{\phi}, & |s| \leq \phi
\end{cases}$$

**方法二：饱和函数**

$$u_{sw} = -\eta \text{sat}(s/\phi)$$

**方法三：连续近似**

$$u_{sw} = -\eta \frac{s}{|s| + \delta}$$

### 4.3 MATLAB 实现

```matlab
function u_sw = chattering_free(s, eta, method, params)
    % 无抖振切换控制

    switch method
        case 'sign'
            % 标准符号函数（有抖振）
            u_sw = -eta * sign(s);

        case 'sat'
            % 饱和函数
            phi = params.phi;
            if abs(s) > phi
                u_sw = -eta * sign(s);
            else
                u_sw = -eta * s / phi;
            end

        case 'tanh'
            % 双曲正切
            delta = params.delta;
            u_sw = -eta * tanh(s / delta);

        case 'sigmoid'
            % Sigmoid 函数
            delta = params.delta;
            u_sw = -eta * s / (abs(s) + delta);
    end
end
```

## 5. 高阶滑模控制

### 5.1 高阶滑模概念

**r 阶滑模**：使 $s, \dot{s}, ..., s^{(r-1)}$ 在有限时间内收敛到零。

### 5.2 超螺旋算法（Super-Twisting）

**超螺旋算法**是二阶滑模，可消除抖振。

**控制律**：

$$u = -k_1 |s|^{1/2} \text{sign}(s) + v$$
$$\dot{v} = -k_2 \text{sign}(s)$$

**MATLAB 实现**：

```matlab
function [u, v] = super_twisting(s, v_prev, k1, k2, dt)
    % 超螺旋算法
    u = -k1 * abs(s)^0.5 * sign(s) + v_prev;
    v = v_prev - k2 * sign(s) * dt;
end
```

### 5.3 积分滑模

**积分滑模**：在滑模面中加入积分项

$$s = \dot{e} + \lambda e + \gamma \int_0^t e(\tau) d\tau$$

**优势**：
- 消除到达阶段
- 从初始时刻就在滑模面上
- 提高鲁棒性

## 6. 滑模控制在无人机中的应用

### 6.1 四旋翼姿态滑模控制

```matlab
function tau = attitude_sliding_mode(phi, theta, psi, p, q, r, ...
    phi_ref, theta_ref, psi_ref, params)
    % 四旋翼姿态滑模控制

    lambda = params.lambda;
    eta = params.eta;

    % 误差
    e_phi = phi - phi_ref;
    e_theta = theta - theta_ref;
    e_psi = psi - psi_ref;

    % 角速率误差（简化）
    e_p = p;
    e_q = q;
    e_r = r;

    % 滑模面
    s_phi = e_p + lambda * e_phi;
    s_theta = e_q + lambda * e_theta;
    s_psi = e_r + lambda * e_psi;

    % 等效控制（忽略耦合）
    tau_phi_eq = -lambda * e_p;
    tau_theta_eq = -lambda * e_q;
    tau_psi_eq = -lambda * e_r;

    % 切换控制
    tau_phi_sw = -eta * sign(s_phi);
    tau_theta_sw = -eta * sign(s_theta);
    tau_psi_sw = -eta * sign(s_psi);

    % 总控制
    tau_phi = tau_phi_eq + tau_phi_sw;
    tau_theta = tau_theta_eq + tau_theta_sw;
    tau_psi = tau_psi_eq + tau_psi_sw;

    tau = [tau_phi; tau_theta; tau_psi];
end
```

### 6.2 自适应滑模控制

```matlab
function [tau, eta_hat] = adaptive_sliding_mode(phi, theta, psi, p, q, r, ...
    eta_hat, params)
    % 自适应滑模控制

    gamma = params.gamma;  % 自适应增益

    % 滑模面
    s = [s_phi; s_theta; s_psi];

    % 自适应律
    eta_hat_dot = gamma * norm(s);
    eta_hat = eta_hat + eta_hat_dot * dt;

    % 控制律
    tau = tau_eq - eta_hat * sign(s);
end
```

## 思考题

1. 滑模控制的"不变性"是什么意思？它适用于哪些类型的不确定性？
2. 为什么超螺旋算法可以消除抖振？它的收敛条件是什么？
3. 积分滑模相比标准滑模有什么优势？在什么情况下使用？
4. 滑模控制在四旋翼姿态控制中如何处理模型不确定性？
5. 如何选择滑模面参数 $\lambda$？它对系统性能有什么影响？

<details>
<summary>参考答案</summary>

1. 不变性：滑模面上系统对匹配不确定性不敏感。匹配不确定性：与控制输入同通道的不确定性。例如：参数变化、外部扰动等。不适用：未匹配不确定性（与控制输入不同通道）。

2. 超螺旋消除抖振：(1) 使用连续控制律，避免 sign 函数；(2) 通过积分项补偿不确定性；(3) 收敛条件：k2 > k1^2/4；(4) 需要不确定性界已知。

3. 积分滑模优势：(1) 消除到达阶段，从初始就在滑模面；(2) 对初始条件鲁棒；(3) 适合需要快速响应的场景；(4) 缺点：积分项可能导致超调。

4. 处理不确定性：(1) 将不确定性视为"扰动"；(2) 滑模面设计使系统在滑模面上对扰动鲁棒；(3) 切换增益需大于不确定性界；(4) 自适应调整切换增益。

5. λ 选择：(1) λ 越大：滑模面越陡，收敛越快，但对噪声敏感；(2) λ 越小：收敛越慢，但更平滑；(3) 经验：λ ≈ 2-5 倍期望带宽；(4) 需要权衡响应速度和鲁棒性。

</details>
