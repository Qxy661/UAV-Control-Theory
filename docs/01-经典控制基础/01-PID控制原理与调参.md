## 1. PID控制概述

PID（Proportional-Integral-Derivative）控制是工业控制中应用最广泛的控制策略，超过 90% 的工业控制回路采用 PID 或其变体。在无人机飞控中，PID 同样是最基础、最常用的控制器。

### 1.1 PID 控制律

连续时间 PID 控制律：

$$u(t) = K_p e(t) + K_i \int_0^t e(\tau)d\tau + K_d \dot{e}(t)$$

其中：
- $e(t) = r(t) - y(t)$：跟踪误差
- $K_p$：比例增益
- $K_i$：积分增益
- $K_d$：微分增益

传递函数形式：

$$C(s) = K_p + \frac{K_i}{s} + K_d s = \frac{K_d s^2 + K_p s + K_i}{s}$$

### 1.2 各项作用分析

```
┌─────────────────────────────────────────────────────────┐
│                    PID 各项作用                           │
├──────────────┬──────────────────────────────────────────┤
│   P (比例)   │  根据当前误差产生控制作用                   │
│              │  优点：响应快                              │
│              │  缺点：存在稳态误差                        │
├──────────────┼──────────────────────────────────────────┤
│   I (积分)   │  消除稳态误差                              │
│              │  优点：零稳态误差                          │
│              │  缺点：超调增大、响应变慢                   │
├──────────────┼──────────────────────────────────────────┤
│   D (微分)   │  预测误差变化趋势                          │
│              │  优点：减小超调、改善动态                   │
│              │  缺点：放大噪声、对突变敏感                 │
└──────────────┴──────────────────────────────────────────┘
```

### 1.3 PID 参数对系统性能的影响

| 参数 | 上升时间 | 超调量 | 稳定时间 | 稳态误差 |
|------|---------|--------|---------|---------|
| $K_p$ ↑ | 减小 | 增大 | 小变化 | 减小 |
| $K_i$ ↑ | 减小 | 增大 | 增大 | 消除 |
| $K_d$ ↑ | 小变化 | 减小 | 减小 | 无影响 |

## 2. PID 控制的物理直觉

### 2.1 比例控制（P）

想象你在开车，前方有一个目标位置。比例控制就像"离目标越远，踩油门越用力"。

```
误差大 → 大油门 → 快速接近
误差小 → 小油门 → 缓慢接近
误差为零 → 不踩油门 → 停止
```

但问题来了：如果有摩擦力，当误差很小时，油门力不足以克服摩擦，车就停了——这就是**稳态误差**。

### 2.2 积分控制（I）

积分控制就像"记住过去的误差"。即使当前误差很小，但只要历史上累积了误差，积分项就会持续增大控制量。

```
误差持续存在 → 积分项不断累积 → 控制量增大 → 最终克服摩擦
```

但积分项有副作用：**积分饱和（Integral Windup）**。当执行器饱和时，误差无法消除，积分项会无限增大，导致大幅超调。

### 2.3 微分控制（D）

微分控制就像"预判未来"。如果误差正在快速减小，微分项会产生反向作用，防止冲过头。

```
误差快速减小 → 微分项为负 → 提前刹车 → 减小超调
```

但微分项对噪声敏感：传感器噪声会被放大。

## 3. PID 调参方法

### 3.1 Ziegler-Nichols 方法

Ziegler-Nichols 是最经典的 PID 调参方法，有两种变体：

**方法一：临界比例法（Ultimate Cycling）**

步骤：
1. 令 $K_i = 0$，$K_d = 0$
2. 逐渐增大 $K_p$，直到系统出现等幅振荡
3. 记录临界增益 $K_u$ 和振荡周期 $T_u$
4. 按下表计算 PID 参数

| 控制器类型 | $K_p$ | $K_i$ | $K_d$ |
|-----------|-------|-------|-------|
| P | $0.5K_u$ | - | - |
| PI | $0.45K_u$ | $0.54K_u/T_u$ | - |
| PID | $0.6K_u$ | $1.2K_u/T_u$ | $0.075K_uT_u$ |

**MATLAB 示例：Ziegler-Nichols 调参与 PID 控制器创建**

```matlab
% Ziegler-Nichols tuning example
Ku = 12; Tu = 0.5; % Ultimate gain and period (from relay experiment)
% PID gains
Kp = 0.6 * Ku;
Ki = 2 * Kp / Tu;
Kd = Kp * Tu / 8;
% Create PID controller in MATLAB
C = pid(Kp, Ki, Kd);
% Plant model (simplified quadrotor attitude)
s = tf('s');
P = 1 / (s^2 + 0.5*s);  % 2nd order attitude plant
% Closed-loop step response
sys_cl = feedback(C * P, 1);
step(sys_cl); title('PID Attitude Control Step Response');
```

**方法二：阶跃响应法（Process Reaction Curve）**

步骤：
1. 开环状态下施加阶跃输入
2. 记录响应曲线，确定延迟时间 $L$ 和时间常数 $T$
3. 计算过程增益 $K = \Delta y / \Delta u$
4. 按下表计算参数

| 控制器类型 | $K_p$ | $K_i$ | $K_d$ |
|-----------|-------|-------|-------|
| P | $T/(KL)$ | - | - |
| PI | $0.9T/(KL)$ | $3.3L$ | - |
| PID | $1.2T/(KL)$ | $2L$ | $0.5L$ |

### 3.2 Cohen-Coon 方法

Cohen-Coon 方法对 Ziegler-Nichols 进行了改进，对大滞后系统效果更好：

$$K_p = \frac{1}{K} \cdot \frac{T}{L} \left(1 + \frac{L}{3T}\right)$$

$$K_i = \frac{L(30 + 3L/T)}{9 + 20L/T}$$

$$K_d = \frac{4L}{11 + 2L/T}$$

### 3.3 继电器自整定（Relay Auto-Tuning）

继电器自整定是一种自动化调参方法，原理如下：

```
┌─────────────────────────────────────────────────┐
│              继电器自整定原理                      │
├─────────────────────────────────────────────────┤
│                                                 │
│   r(t) ──→ [继电器] ──→ [被控对象] ──→ y(t)     │
│              ↑               │                  │
│              │               │                  │
│              └───────────────┘                  │
│                                                 │
│   继电器输出：幅值为 d 的方波                      │
│   系统产生极限环振荡                              │
│   测量振荡周期 Tu 和幅值 a                        │
│   计算：Ku = 4d/(πa)                            │
│                                                 │
└─────────────────────────────────────────────────┘
```

**MATLAB 实现**：

```matlab
% 继电器自整定示例
function [Ku, Tu] = relay_auto_tune(sys, d, t_final)
    % sys: 被控对象传递函数
    % d: 继电器幅值
    % t_final: 仿真时间

    % 搭建继电器反馈回路
    sim_out = sim('relay_tuning_model');

    % 从仿真结果提取振荡周期和幅值
    y = sim_out.y;
    t = sim_out.t;

    % 寻找过零点确定周期
    crossings = find(diff(sign(y - mean(y))));
    Tu = mean(diff(t(crossings)));

    % 计算振荡幅值
    a = (max(y) - min(y)) / 2;

    % 计算临界增益
    Ku = 4 * d / (pi * a);
end
```

## 4. 频域分析视角

> **延伸阅读**：频域分析的完整理论（Bode图、Nyquist判据、稳定裕度、超前-滞后补偿器设计）详见 [频域分析与设计](./02-频域分析与设计.md)。

### 4.1 PID 的频率响应

PID 控制器的频率响应：

$$C(j\omega) = K_p + \frac{K_i}{j\omega} + K_d j\omega$$

```
频率响应特性：

  增益(dB)
    │
    │         ╱ K_d (高频，微分主导)
    │        ╱
    │───────╱──── K_p (中频，比例主导)
    │      ╱
    │     ╱
    │    ╱
    │╲  ╱
    │ ╲╱  K_i (低频，积分主导)
    │
    └──────────────────────── 频率(rad/s)
```

### 4.2 整定规则与频域指标

| 频域指标 | 典型要求 | PID 参数影响 |
|---------|---------|-------------|
| 增益裕度 (GM) | > 6 dB | $K_p$ 增大 → GM 减小 |
| 相位裕度 (PM) | > 45° | $K_d$ 增大 → PM 增大 |
| 带宽 (BW) | 满足响应速度要求 | $K_p$ 增大 → BW 增大 |
| 截止频率 $\omega_c$ | 约为期望带宽 | 由 $K_p$ 和 $K_d$ 决定 |

## 5. 工程实现中的关键问题

### 5.1 抗积分饱和（Anti-Windup）

**问题描述**：当执行器饱和时，误差无法消除，积分项持续增大，导致大幅超调。

**解决方案一：条件积分**

```matlab
% 条件积分：仅在执行器未饱和时积分
if abs(u) < u_max
    integral = integral + e * dt;
else
    integral = integral;  % 冻结积分
end
```

**解决方案二：反计算（Back-Calculation）**

```matlab
% 反计算抗积分饱和
u_unsat = Kp * e + Ki * integral + Kd * derivative;
u = max(min(u_unsat, u_max), -u_min);
integral = integral + (e + (u - u_unsat) / Kb) * dt;
% Kb 为反计算增益，通常取 Ki 的 0.1-10 倍
```

**解决方案三：积分限幅**

```matlab
% 积分项限幅
integral = integral + e * dt;
integral = max(min(integral, I_max), -I_max);
```

### 5.2 微分项的实现

**问题**：直接对误差微分会放大噪声。

**解决方案一：微分先行（Derivative on PV）**

```matlab
% 微分项作用于过程变量而非误差
derivative = -Kd * dy/dt;  % 对 y 微分，而非对 e 微分
```

**解决方案二：不完全微分（Filtered Derivative）**

```matlab
% 一阶滤波微分
alpha = Tf / (Tf + dt);  % Tf 为滤波时间常数
derivative = alpha * derivative_prev + (1 - alpha) * (e - e_prev) / dt;
```

传递函数形式：

$$C_d(s) = \frac{K_d s}{T_f s + 1}$$

### 5.3 离散化实现

**位置式 PID**：

```matlab
function u = pid_position(e, e_prev, integral, dt, Kp, Ki, Kd, Tf)
    % 比例项
    P = Kp * e;

    % 积分项（梯形法）
    integral = integral + (e + e_prev) / 2 * dt;
    I = Ki * integral;

    % 微分项（不完全微分）
    alpha = Tf / (Tf + dt);
    derivative = alpha * derivative_prev + ...
                 (1 - alpha) * (e - e_prev) / dt;
    D = Kd * derivative;

    % 输出
    u = P + I + D;
end
```

**增量式 PID**：

```matlab
function du = pid_incremental(e, e_prev, e_prev2, dt, Kp, Ki, Kd)
    % 增量式 PID：输出为控制量增量
    du = Kp * (e - e_prev) ...
       + Ki * e * dt ...
       + Kd * (e - 2*e_prev + e_prev2) / dt;
end
```

**增量式 PID 的优势**：
- 无积分项，不存在积分饱和问题
- 输出为增量，便于实现无扰切换
- 计算量小，适合嵌入式实现

## 6. Simulink 实现

### 6.1 基本 PID 控制器搭建

```matlab
% Simulink 模型搭建脚本
% 创建 PID 控制器子系统

function create_pid_subsystem(model_name)
    % 新建模型
    new_system(model_name);
    open_system(model_name);

    % 添加模块
    add_block('simulink/Math Operations/Sum', [model_name '/Sum']);
    add_block('simulink/Continuous/PID Controller', [model_name '/PID']);
    add_block('simulink/Continuous/Transfer Fcn', [model_name '/Plant']);

    % 设置参数
    set_param([model_name '/Sum'], 'Inputs', '+-');
    set_param([model_name '/PID'], 'P', '1', 'I', '0.1', 'D', '0.01');
    set_param([model_name '/Plant'], 'Numerator', '[1]', ...
              'Denominator', '[1 2 1]');

    % 连线
    add_line(model_name, 'In1/1', 'Sum/1');
    add_line(model_name, 'Sum/1', 'PID/1');
    add_line(model_name, 'PID/1', 'Plant/1');
    add_line(model_name, 'Plant/1', 'Out1/1');
    add_line(model_name, 'Plant/1', 'Sum/2');

    save_system(model_name);
end
```

## 7. PID 在无人机中的应用

### 7.1 姿态环 PID 控制

```
           ┌─────────┐     ┌─────────┐     ┌─────────┐
  φ_ref ──→│  外环   │──→  │  内环   │──→  │  无人机 │──→ φ
           │ (角度)  │     │(角速率) │     │  动力学 │
           │  PID    │     │  PID    │     │         │
           └─────────┘     └─────────┘     └─────────┘
               ↑                               │
               └───────────────────────────────┘
```

**典型参数范围**（四旋翼姿态控制）：

| 参数 | 外环（角度） | 内环（角速率） |
|------|------------|--------------|
| $K_p$ | 4.0 - 8.0 | 0.1 - 0.3 |
| $K_i$ | 0.1 - 0.5 | 0.01 - 0.05 |
| $K_d$ | 0.0 - 0.1 | 0.005 - 0.015 |

### 7.2 位置环 PID 控制

```matlab
% 四旋翼位置控制 PID 参数示例
% X/Y 位置环
Kp_xy = 1.0;   Ki_xy = 0.1;   Kd_xy = 0.5;

% Z 位置环（高度控制）
Kp_z = 2.0;    Ki_z = 0.5;    Kd_z = 1.0;

% 限幅
u_max_xy = 15;  % 最大倾斜角（度）
u_max_z = 100;  % 最大油门（%）
```

### 7.3 PID 调参注意事项

**四旋翼 PID 调参顺序**：
1. 先调内环（角速率环）→ 确保角速率跟踪性能
2. 再调外环（角度环）→ 确保角度跟踪性能
3. 最后调位置环 → 确保位置跟踪性能

**常见问题与解决**：

| 问题 | 可能原因 | 解决方法 |
|------|---------|---------|
| 高频振荡 | $K_d$ 过大或噪声 | 降低 $K_d$，增加滤波 |
| 低频振荡 | $K_p$ 过大 | 降低 $K_p$ |
| 超调过大 | $K_i$ 过大 | 降低 $K_i$，增加 $K_d$ |
| 稳态误差 | $K_i$ 过小 | 增大 $K_i$ |
| 响应太慢 | 所有增益偏小 | 适当增大 $K_p$ |

## 8. PID 的局限性与改进方向

### 8.1 PID 的主要局限

```
┌─────────────────────────────────────────────────┐
│              PID 控制的局限性                      │
├─────────────────────────────────────────────────┤
│                                                 │
│  1. 线性控制器，对非线性系统性能有限               │
│  2. 无法显式处理约束（执行器饱和、状态约束）        │
│  3. 参数固定，对参数变化和扰动适应性有限            │
│  4. MIMO 系统耦合处理困难                         │
│  5. 无法利用系统模型信息                           │
│                                                 │
└─────────────────────────────────────────────────┘
```

### 8.2 改进方向

> **相关章节**：多回路级联 PID 是无人机控制的核心架构，其设计原则（带宽分离、内外环独立调参）详见 [多回路与级联控制](./05-多回路与级联控制.md)。

| 改进方向 | 方法 | 适用场景 |
|---------|------|---------|
| 非线性 PID | 增益调度、模糊 PID | 工作点变化大 |
| 自适应 PID | MRAC、神经网络 PID | 参数不确定 |
| 预测 PID | MPC + PID 结构 | 有约束要求 |
| 鲁棒 PID | H-infinity PID | 模型不确定性大 |
| ADRC | 自抗扰控制 | 大范围扰动 |

<details>
<summary>参考答案</summary>

1. 级联 PID 的优势：(1) 内环（角速率环）带宽高，能快速抑制扰动；(2) 外环（角度环）带宽较低，提供稳定的角度跟踪；(3) 带宽分离设计使各环独立调试，简化参数整定；(4) 内环对模型不确定性有更好的鲁棒性。

2. 积分饱和场景：四旋翼从大角度快速恢复时，姿态误差很大，积分项快速累积。当电机已满油门（饱和）但误差仍存在时，积分继续增大。当姿态恢复后，过大的积分项会导致大幅反向超调，甚至翻机。

3. 微分先行的优势：(1) 避免设定值突变时微分项产生尖峰（无人机姿态参考值可能阶跃变化）；(2) 减少对设定值噪声的放大；(3) 仅对过程变量（传感器测量值）微分，反映系统真实动态。在无人机中，设定值可能来自上位机指令，噪声较小，而传感器信号可通过滤波处理。

4. 低频振荡可能原因：(1) $K_p$ 过大导致系统接近不稳定边界；(2) 机械结构共振（如桨叶不平衡）；(3) 传感器延迟过大（如 GPS 更新率低）。解决方法：降低 $K_p$，检查机械结构，增加滤波或降低外环带宽。

5. 增量式 PID 优势：(1) 输出为控制量增量，便于实现无扰切换（模式切换时不会跳变）；(2) 无积分项累积，不存在积分饱和问题；(3) 仅需保存最近三次误差，内存占用小；(4) 计算量小，适合高频率运行（飞控典型 400-1000 Hz）。

</details>
