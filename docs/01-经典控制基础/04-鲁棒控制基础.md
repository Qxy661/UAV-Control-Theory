## 1. 鲁棒控制概述

鲁棒控制研究的是：**当系统存在不确定性时，如何设计控制器保证性能和稳定性**。

### 1.1 不确定性的来源

```
┌─────────────────────────────────────────────────┐
│              系统不确定性的来源                    │
├─────────────────────────────────────────────────┤
│                                                 │
│  1. 参数不确定性                                  │
│     ├── 质量变化（载荷变化）                      │
│     ├── 转动惯量变化                             │
│     └── 气动参数变化                             │
│                                                 │
│  2. 未建模动态                                    │
│     ├── 高频柔性模态                             │
│     ├── 执行器动态                               │
│     └── 传感器动态                               │
│                                                 │
│  3. 外部扰动                                     │
│     ├── 风扰动                                   │
│     ├── 地面效应                                 │
│     └── 电磁干扰                                 │
│                                                 │
│  4. 线性化误差                                    │
│     ├── 工作点偏离                               │
│     └── 大角度运动                               │
│                                                 │
└─────────────────────────────────────────────────┘
```

### 1.2 鲁棒性的定义

**鲁棒稳定性**：当系统存在不确定性时，闭环系统仍然稳定。

**鲁棒性能**：当系统存在不确定性时，闭环系统仍然满足性能指标。

## 2. 不确定性建模

### 2.1 参数不确定性

**结构化不确定性**：参数在已知范围内变化。

$$G(s, \delta) = G_0(s) + \Delta G(s, \delta)$$

其中 $\delta \in [\delta_{min}, \delta_{max}]$ 为不确定参数。

**示例**：四旋翼质量不确定性

$$m = m_0 + \Delta m, \quad \Delta m \in [-0.5, 0.5] \text{ kg}$$

### 2.2 非结构化不确定性

**加性不确定性**：

$$G_p(s) = G_0(s) + \Delta_a(s)$$

**乘性不确定性**：

$$G_p(s) = G_0(s)(1 + \Delta_m(s))$$

**输入乘性不确定性**：

$$G_p(s) = (1 + \Delta_i(s))G_0(s)$$

```
不确定性模型对比：

加性：  G_p = G_0 + Δ_a
乘性：  G_p = G_0(1 + Δ_m)
输入：  G_p = (1 + Δ_i)G_0

物理意义：
├── 加性：直接叠加的不确定性（如传感器噪声）
├── 乘性：相对变化的不确定性（如参数变化）
└── 输入：输入端的不确定性（如执行器误差）
```

### 2.3 不确定性界函数

**加性不确定性界**：

$$|\Delta_a(j\omega)| \leq l_a(\omega)$$

**乘性不确定性界**：

$$|\Delta_m(j\omega)| \leq l_m(\omega)$$

```matlab
% 不确定性界函数示例
% 乘性不确定性界：低频 10%，高频 100%
w = logspace(-2, 3, 1000);
l_m = 0.1 + 0.9 * (w/100).^2 ./ (1 + (w/100).^2);

% 绘制不确定性界
semilogx(w, 20*log10(l_m));
xlabel('频率 (rad/s)');
ylabel('不确定性界 (dB)');
title('乘性不确定性界');
grid on;
```

## 3. H-infinity 控制

### 3.1 H-infinity 范数

**H-infinity 范数定义**：

$$\|G\|_\infty = \sup_{\omega} \bar{\sigma}(G(j\omega))$$

其中 $\bar{\sigma}$ 是最大奇异值。

**物理意义**：H-infinity 范数是系统频率响应的最大增益。

### 3.2 小增益定理

**小增益定理**：如果两个稳定系统 $G$ 和 $\Delta$ 满足：

$$\|G\|_\infty \cdot \|\Delta\|_\infty < 1$$

则反馈连接系统稳定。

**应用**：对于乘性不确定性 $\Delta_m$，闭环稳定的充分条件是：

$$\|T\|_\infty < 1 / l_m$$

其中 $T$ 是补灵敏度函数。

### 3.3 H-infinity 控制问题

**标准 H-infinity 问题**：

```
┌─────────────────────────────────────────────────┐
│              H-infinity 标准问题                  │
├─────────────────────────────────────────────────┤
│                                                 │
│         ┌───────┐                               │
│    z ←──│       │←── w                          │
│         │  P    │                               │
│    y ←──│       │←── u                          │
│         └───────┘                               │
│              ↑                                  │
│              │                                  │
│         ┌───────┐                               │
│         │   K   │                               │
│         └───────┘                               │
│                                                 │
│  P：广义被控对象                                 │
│  K：控制器                                      │
│  w：外部输入（扰动、噪声）                       │
│  z：性能输出（跟踪误差、控制量）                  │
│  y：测量输出                                    │
│  u：控制输入                                    │
│                                                 │
│  目标：最小化 ‖T_zw‖∞                           │
│                                                 │
└─────────────────────────────────────────────────┘
```

### 3.4 MATLAB H-infinity 设计

```matlab
% H-infinity 控制器设计示例
% 被控对象
s = tf('s');
G = 10 / (s*(s+1));

% 权重函数选择
% 性能权重：低频高增益（跟踪性能）
Wp = (s/10 + 1) / (s/0.1 + 1);

% 控制权重：高频高增益（抑制高频控制）
Wu = (s/100 + 1) / (s/10 + 1);

% 灵敏度权重
Wt = (s/50 + 1) / (s/100 + 1);

% 构建广义对象
P = augw(G, Wp, Wu, Wt);

% 设计 H-infinity 控制器
[K, CL, gamma] = hinfsyn(P, 1, 1);

% gamma: 最优 H-infinity 性能指标
fprintf('H-infinity 性能指标 γ = %.4f\n', gamma);

% 闭环系统分析
L = G * K;  % 开环传递函数
S = feedback(1, L);  % 灵敏度函数
T = feedback(L, 1);  % 补灵敏度函数

% 验证性能
figure;
bode(S, Wp^-1);
title('灵敏度函数与性能权重');
legend('S', '1/Wp');
```

## 4. 结构化不确定性与 mu 综合

### 4.1 结构化不确定性

**结构化奇异值（Structured Singular Value, SSV）**：

$$\mu_\Delta(M) = \frac{1}{\min\{\bar{\sigma}(\Delta) : \det(I - M\Delta) = 0, \Delta \in \mathbf{\Delta}\}}$$

其中 $\mathbf{\Delta}$ 是结构化不确定性集合。

### 4.2 mu 综合

**D-K 迭代**：

```
┌─────────────────────────────────────────────────┐
│              D-K 迭代流程                         │
├─────────────────────────────────────────────────┤
│                                                 │
│  1. 初始化 D = I                                │
│                                                 │
│  2. 固定 D，求解 H-infinity 问题得 K             │
│     min_K ‖F_l(P, K)‖∞                         │
│                                                 │
│  3. 固定 K，优化 D 使 μ 最小                     │
│     min_D μ_Δ(D F_l(P,K) D^-1)                 │
│                                                 │
│  4. 重复 2-3 直到收敛                            │
│                                                 │
└─────────────────────────────────────────────────┘
```

### 4.3 MATLAB mu 综合

```matlab
% mu 综合设计示例
% 定义不确定性
m_real = ureal('m', 1.5, 'Percentage', 20);  % 质量 ±20%
J_real = ureal('J', 0.01, 'Percentage', 15); % 惯量 ±15%

% 构建含不确定性的状态空间模型
A_unc = [0 1; 0 0];
B_unc = [0; 1/J_real];
C_unc = [1 0];
D_unc = 0;
sys_unc = ss(A_unc, B_unc, C_unc, D_unc);

% 权重函数
Wp = makeweight(100, 10, 0.1);
Wu = makeweight(0.1, 100, 100);

% 构建广义对象
P = augw(sys_unc, Wp, Wu, []);

% D-K 迭代
[K, CL, gamma] = dksyn(P, 1, 1);

% mu 分析
[mu_bounds] = musyn(CL);

% 绘制 mu 值
bodemag(mu_bounds);
title('结构化奇异值 μ');
```

```matlab
% H-infinity PID 设计
% 被控对象（含不确定性）
G_unc = tf(10, [1 1]) * (1 + 0.2*ultidyn('d', [1 1], 'Bound', 1));

% PID 控制器结构
C = tunablePID('C', 'pid');

% 连接
T = feedback(G_unc*C, 1);

% H-infinity 优化目标
Req = [TuningGoal.Tracking(1, 0.1, 0.01);  % 跟踪性能
       TuningGoal.Rejection('d', 0.1, 0.1)];  % 扰动抑制

% 优化
[T_opt, fopt] = systune(T, Req);

% 提取 PID 参数
C_opt = getBlockValue(T_opt, 'C');
[Kp, Ki, Kd] = piddata(C_opt);
```

### 7.4 风扰动建模

前面在不确定性来源（第1节）和控制框架（7.1节）中都提到了风扰动，但没有给出具体的数学模型。本节介绍工程中常用的 Dryden 风湍流模型，用于鲁棒性测试和控制器验证。

#### 7.4.1 Dryden 湍流模型

Dryden 模型将大气湍流描述为白噪声通过成形滤波器后的输出，其功率谱密度与真实大气湍流统计特性吻合。

**纵向湍流分量**的传递函数：

$$H_u(s) = \sigma_u \sqrt{\frac{2 L_u}{\pi V}} \cdot \frac{1}{1 + \frac{L_u}{V} s}$$

**垂直湍流分量**的传递函数：

$$H_w(s) = \sigma_w \sqrt{\frac{2 L_w}{\pi V}} \cdot \frac{1}{1 + \frac{2 L_w}{V} s}$$

其中：
- $\sigma_u, \sigma_w$：湍流强度（m/s），取决于天气条件
- $L_u, L_w$：湍流长度尺度（m），与飞行高度相关
- $V$：飞行器空速（m/s）

**湍流强度参考值**：

| 天气条件 | $\sigma$ (m/s) | 说明 |
|---------|----------------|------|
| 轻度湍流 | 0.5 - 1.5 | 晴天微风 |
| 中度湍流 | 1.5 - 3.0 | 多云有风 |
| 重度湍流 | 3.0 - 6.0 | 强风或对流天气 |

**长度尺度与高度的关系**（MIL-F-8785C 标准）：

$$L_u = L_w = \begin{cases} h & h < 300 \text{ m} \\ 300 & h \geq 300 \text{ m} \end{cases}$$

```matlab
% Dryden Wind Turbulence Model for Control Design
% Generate wind disturbance for robustness testing
function wind = dryden_for_control(V, h, sigma, t)
    % Simplified Dryden model for control analysis
    % V: airspeed, h: altitude, sigma: turbulence intensity, t: time vector
    dt = t(2) - t(1);
    L = max(h, 10);  % turbulence length scale

    % Longitudinal component (first-order filter on white noise)
    tau = L / V;
    a = exp(-dt/tau);
    K = sigma * sqrt(2*dt/tau);
    wind.u = filter(K, [1, -a], randn(size(t)));

    % Vertical component
    wind.w = filter(K, [1, -a], randn(size(t)));

    % Add steady-state wind
    wind.u = wind.u + 3;  % 3 m/s steady headwind
end

% Robustness test: sweep wind speeds
wind_speeds = 0:2:15;
for ws = wind_speeds
    % Simulate with wind disturbance
    % Check if PID maintains stability
    fprintf('Wind %d m/s: max attitude error = %.2f deg\n', ws, max_err);
end
```

#### 7.4.2 频域分析：带宽与风扰动抑制

风扰动抑制能力取决于闭环系统的带宽和灵敏度函数。关键关系如下：

**扰动抑制条件**：在扰动频率 $\omega_d$ 处，灵敏度函数 $S(j\omega_d)$ 的幅值决定了该频率的扰动抑制效果。

$$|S(j\omega_d)| < 1 \quad \Rightarrow \quad \text{扰动被衰减}$$

**风扰动的频率特性**：
- 稳态风（常值偏置）：$\omega \approx 0$，需要积分作用抑制
- 阵风（低频）：$\omega \in [0.1, 1]$ rad/s，需要足够的带宽覆盖
- 湍流（中频）：$\omega \in [1, 10]$ rad/s，需要良好的灵敏度特性

**设计准则**：闭环带宽 $\omega_{BW}$ 应满足：

$$\omega_{BW} > 3 \cdot \omega_{gust,max}$$

其中 $\omega_{gust,max}$ 是需要抑制的最大阵风频率。对于典型的四旋翼，要求 $\omega_{BW} > 3$ rad/s。

```matlab
% 频域分析：闭环带宽与风扰动抑制
s = tf('s');

% 被控对象（滚转通道）
J = 0.01;   % 转动惯量
b = 0.01;   % 阻尼
G = 1 / (J*s^2 + b*s);

% PID 控制器
Kp = 5; Ki = 2; Kd = 0.5;
C = Kp + Ki/s + Kd*s;

% 闭环传递函数
L = G * C;              % 开环
S = feedback(1, L);     % 灵敏度函数（扰动到输出）
T = feedback(L, 1);     % 补灵敏度函数

% 绘制灵敏度函数
figure;
bodemag(S);
hold on;

% 标注风扰动频率范围
xline(0.1, '--r', '阵风下限');
xline(10, '--r', '湍流上限');
title('灵敏度函数与风扰动频率范围');
ylabel('幅值 (dB)');
grid on;

% 计算不同频率的扰动抑制比
w_test = [0.1, 0.5, 1, 2, 5, 10];
fprintf('频率(rad/s) | |S(jw)| | 抑制比(dB)\n');
fprintf('-----------|---------|----------\n');
for w = w_test
    S_mag = abs(evalfr(S, 1j*w));
    fprintf('%10.1f | %7.4f | %8.2f dB\n', w, S_mag, 20*log10(S_mag));
end

% 闭环带宽
BW = bandwidth(T);
fprintf('\n闭环带宽: %.2f rad/s\n', BW);

% 验证设计准则
w_gust_max = 5;  % 最大阵风频率
if BW > 3 * w_gust_max
    fprintf('满足带宽要求: %.1f > 3 x %.1f = %.1f rad/s\n', ...
            BW, w_gust_max, 3*w_gust_max);
else
    fprintf('警告: 带宽不足! %.1f < %.1f rad/s\n', BW, 3*w_gust_max);
end
```

**灵敏度峰值约束**：为保证鲁棒性，灵敏度峰值应满足：

$$\|S\|_\infty = \max_\omega |S(j\omega)| < 6 \text{ dB}$$

若 $\|S\|_\infty$ 过大，说明系统在某个频率附近对扰动放大，可能导致风扰动下的振荡。

---

## 8. 总结

### 8.1 鲁棒控制的关键概念

| 概念 | 含义 |
|------|------|
| 不确定性 | 系统模型与真实系统的差异 |
| 鲁棒稳定性 | 不确定性下系统仍稳定 |
| 鲁棒性能 | 不确定性下系统仍满足性能 |
| H-infinity 范数 | 最大频率响应增益 |
| 小增益定理 | 鲁棒稳定的充分条件 |
| mu 综合 | 处理结构化不确定性的方法 |

### 8.2 选择指南

```
何时使用鲁棒控制？
├── 模型不确定性大（> 20%）
├── 需要严格的性能保证
├── 系统工作范围宽
└── 安全性要求高

何时使用 PID？
├── 模型不确定性小（< 10%）
├── 工程实现简单优先
├── 调参经验丰富
└── 计算资源有限
```

## 思考题

1. 为什么说 H-infinity 控制是"最坏情况"设计？这种方法有什么优缺点？
2. 小增益定理的物理意义是什么？它在无人机鲁棒控制中有什么应用？
3. mu 综合相比 H-infinity 控制有什么优势？为什么需要 D-K 迭代？
4. 在四旋翼控制中，哪些不确定性适合用结构化不确定性建模，哪些适合用非结构化不确定性建模？
5. 如何在鲁棒性和性能之间取得平衡？请举例说明。

<details>
<summary>参考答案</summary>

1. H-infinity 控制是最坏情况设计，因为它最小化最大频率响应增益，即考虑所有频率中最不利的情况。优点：对所有频率范围内的不确定性都有鲁棒性保证。缺点：可能过于保守，对某些工作点性能过度设计。

2. 小增益定理的物理意义：如果开环系统的增益乘积小于 1，则反馈连接系统稳定。在无人机中应用：如果控制器增益与不确定性增益的乘积在所有频率上小于 1，则闭环系统鲁棒稳定。

3. mu 综合优势：(1) 能处理结构化不确定性（如多个参数同时变化），而 H-infinity 只能处理非结构化不确定性；(2) 减少保守性，因为利用了不确定性的结构信息。D-K 迭代是求解 mu 综合的数值方法，交替优化控制器 K 和标度矩阵 D。

4. 结构化不确定性：质量、惯量、气动参数（已知变化范围的参数）。非结构化不确定性：未建模动态、执行器延迟、高频柔性模态（难以精确建模的部分）。

5. 平衡方法：(1) 调整权重函数：降低性能权重可提高鲁棒性，反之亦然；(2) 使用混合灵敏度设计：同时优化灵敏度 S、补灵敏度 T 和控制灵敏度 KS；(3) 在不同频率范围设置不同要求：低频重性能，高频重鲁棒性。

</details>
