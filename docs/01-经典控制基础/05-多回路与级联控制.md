## 1. 级联控制概述

级联控制（Cascade Control）是无人机飞控中最常用的控制结构。它将系统分解为多个嵌套的控制回路，每个回路负责不同的控制目标。

### 1.1 为什么使用级联控制？

```
单环控制的问题：
├── 系统阶次高，控制器设计复杂
├── 扰动从输入到输出路径长，响应慢
├── 非线性特性难以处理
└── 参数整定困难

级联控制的优势：
├── 降低每个回路的设计复杂度
├── 内环快速抑制扰动
├── 带宽分离简化设计
├── 便于故障诊断和模式切换
└── 工程经验丰富，便于调试
```

### 1.2 级联控制基本结构

```
┌─────────────────────────────────────────────────┐
│              级联控制基本结构                      │
├─────────────────────────────────────────────────┤
│                                                 │
│  r(t) ──→ [外环控制器] ──→ [内环控制器] ──→ [对象] ──→ y(t)
│                ↑              ↑            │      │
│                │              │            │      │

│                                                 │

│  内环：快回路，处理高频信号                        │
│                                                 │
└─────────────────────────────────────────────────┘
```

## 2. 带宽分离设计原则

### 2.1 带宽定义

**带宽（Bandwidth）**：系统频率响应下降到 -3 dB 时的频率。

```
带宽的物理意义：
├── 带宽越大：系统响应越快
├── 带宽越小：系统响应越慢
├── 带宽过高：放大噪声
└── 带宽过低：跟踪性能差
```

### 2.2 带宽分离原则

**原则**：相邻环路的带宽比至少 5-10 倍。

```
┌─────────────────────────────────────────────────┐
│              带宽分离示意图                        │
├─────────────────────────────────────────────────┤
│                                                 │
│  带宽(rad/s)                                    │
│    │                                            │
│ 100│  ┌─────────────┐                           │
│    │  │ 执行器带宽   │                           │
│  50│  └──────┬──────┘                           │
│    │         │                                  │
│  20│  ┌──────┴──────┐                           │
│    │  │ 内环带宽     │ ← 角速率环                │
│  10│  └──────┬──────┘                           │
│    │         │                                  │
│   5│  ┌──────┴──────┐                           │
│    │  │ 外环带宽     │ ← 角度环                  │
│   1│  └──────┬──────┘                           │
│    │         │                                  │
│ 0.5│  ┌──────┴──────┐                           │
│    │  │ 最外环带宽   │ ← 位置环                  │
│    │  └─────────────┘                           │
│    └──────────────────────────────              │
│                                                 │
│  带宽比：内环/外环 ≈ 5-10                        │
│                                                 │
└─────────────────────────────────────────────────┘
```

### 2.3 带宽选择考虑因素

| 因素 | 影响 | 选择原则 |
|------|------|---------|
| 执行器动态 | 限制最大带宽 | 内环带宽 < 执行器带宽/2 |
| 传感器噪声 | 限制最大带宽 | 带宽 < 噪声频率 |
| 采样率 | 限制最大带宽 | 带宽 < 采样频率/10 |
| 模型不确定性 | 限制最大带宽 | 不确定性大时降低带宽 |
| 响应速度 | 要求高带宽 | 满足性能指标 |

### 3.2 各环路设计参数

| 环路 | 带宽 (rad/s) | 更新率 (Hz) | 典型 Kp | 典型 Ki | 典型 Kd |
|------|-------------|------------|---------|---------|---------|
| 角速率环 | 30-50 | 400-1000 | 0.1-0.3 | 0.01-0.05 | 0.005-0.015 |

### 3.3 MATLAB 实现

```matlab
% 四旋翼级联控制 Simulink 模型搭建脚本

function create_cascade_controller(model_name)
    % 新建模型
    new_system(model_name);
    open_system(model_name);

    % 位置环
    add_block('simulink/Continuous/PID Controller', ...
              [model_name '/Position_PID']);
    set_param([model_name '/Position_PID'], ...
              'P', '1.0', 'I', '0.1', 'D', '0.5');

    % 姿态环
    add_block('simulink/Continuous/PID Controller', ...
              [model_name '/Attitude_PID']);
    set_param([model_name '/Attitude_PID'], ...
              'P', '5.0', 'I', '0.2', 'D', '0.05');

    % 角速率环
    add_block('simulink/Continuous/PID Controller', ...
              [model_name '/Rate_PID']);
    set_param([model_name '/Rate_PID'], ...
              'P', '0.2', 'I', '0.02', 'D', '0.01');

    % 连线和配置...
    save_system(model_name);
end

## 4. MIMO 解耦控制

### 4.1 耦合问题

四旋翼的四个通道（滚转、俯仰、偏航、油门）之间存在耦合：

```
耦合来源：
├── 动力学耦合：角速度之间的陀螺耦合
├── 运动学耦合：姿态变化影响位置
├── 执行器耦合：电机推力影响多个通道
└── 气动耦合：旋翼之间的气动干扰
```

### 4.2 解耦方法

**方法一：前馈解耦**

```

│  u₂ ──→ │ 解耦   │ ──→ τ_θ                     │
│          │ 矩阵   │                              │

│  τ = D * u                                      │

## 5. 级联控制的稳定性分析

### 5.1 内环稳定性

内环设计时需确保：
- 内环本身稳定
- 内环带宽足够高
- 内环对模型不确定性鲁棒

```matlab
% 内环稳定性验证
L_inner = G_inner * C_inner;  % 内环开环传递函数
S_inner = feedback(1, L_inner);  % 内环灵敏度函数
T_inner = feedback(L_inner, 1);  % 内环补灵敏度函数

% 检查稳定裕度
[Gm, Pm, Wcg, Wcp] = margin(L_inner);
fprintf('内环增益裕度: %.2f dB\n', 20*log10(Gm));
fprintf('内环相位裕度: %.2f°\n', Pm);
```

### 5.2 级联系统稳定性

**分离设计原理**：当内环带宽远大于外环带宽时，可将内环视为"理想化"的执行器。

```
级联系统稳定性条件：
├── 内环稳定且带宽足够高
├── 外环设计时将内环视为增益为1的环节
├── 内外环带宽比 > 5-10
└── 内环对参数变化不敏感
```

### 5.3 MATLAB 级联系统分析

```matlab
% 级联系统分析
% 内环
G_inner = tf(1, [0.01 1]);  % 执行器简化模型
C_inner = pid(0.2, 0.02, 0.01);
L_inner = G_inner * C_inner;
T_inner = feedback(L_inner, 1);

% 外环
G_outer = T_inner * tf(1, [1 0]);  % 积分环节
C_outer = pid(5, 0.2, 0.05);
L_outer = G_outer * C_outer;

% 级联系统分析
margin(L_outer);
title('外环开环 Bode 图');

% 闭环响应
sys_cl = feedback(L_outer, 1);
step(sys_cl);
title('级联系统阶跃响应');
```

## 6. 级联控制的工程实践

### 6.1 调参顺序

```
级联控制调参顺序：

步骤1：调内环（角速率环）
├── 先 P 后 I 再 D
├── 确保角速率跟踪性能
└── 验证稳定裕度

步骤2：调外环（角度环）
├── 将内环视为"理想执行器"
├── 设计角度跟踪性能
└── 验证级联稳定性

步骤3：调位置环
├── 将姿态环视为"理想执行器"
├── 设计位置跟踪性能
└── 验证整体性能

步骤4：整体验证
├── 蒙特卡洛仿真
├── 参数鲁棒性测试
└── 飞行测试
```

### 6.2 常见问题与解决

| 问题 | 可能原因 | 解决方法 |
|------|---------|---------|
| 内环振荡 | Kp 过大 | 降低内环 Kp |
| 外环超调 | 带宽比不足 | 增大内环带宽或降低外环带宽 |
| 低频漂移 | 积分不足 | 增大外环 Ki |
| 高频噪声 | 微分过大 | 降低 Kd 或增加滤波 |
| 通道耦合 | 解耦不足 | 增加前馈解耦 |

### 6.3 PX4 飞控级联控制

PX4 飞控采用经典的级联 PID 结构：

```
PX4 级联控制结构：

位置环 (EKF2 更新率 ~100Hz)
├── 输入：位置误差
├── 输出：期望速度/期望姿态
└── 参数：MPC_XY_P, MPC_Z_P

速度环 (EKF2 更新率 ~100Hz)
├── 输入：速度误差
├── 输出：期望加速度/期望姿态
└── 参数：MPC_XY_VEL_P_ACC, MPC_XY_VEL_I_ACC

姿态环 (IMU 更新率 ~400Hz)
├── 输入：姿态误差
├── 输出：期望角速率
└── 参数：MC_ROLL_P, MC_PITCH_P, MC_YAW_P

角速率环 (IMU 更新率 ~400Hz)
├── 输入：角速率误差
├── 输出：电机控制量
└── 参数：MC_ROLLRATE_P, MC_ROLLRATE_I, MC_ROLLRATE_D
```

## 8. 总结

### 8.1 级联控制设计要点

| 要点 | 说明 |
|------|------|
| 带宽分离 | 相邻环路带宽比 5-10 倍 |
| 调参顺序 | 从内环到外环 |
| 稳定性验证 | 内环和级联系统都要验证 |
| 解耦处理 | 通道间耦合需前馈解耦 |
| 鲁棒性设计 | 考虑参数变化和扰动 |

### 8.2 与其他方法的对比

| 方法 | 优势 | 劣势 | 适用场景 |
|------|------|------|---------|
| 级联 PID | 简单、工程实用 | 性能有限 | 大多数 UAV |
| 级联 LQR | 最优性、系统化 | 需精确模型 | 研究验证 |
| 级联 MPC | 处理约束 | 计算量大 | 约束严格场景 |
| 级联 ADRC | 不依赖模型 | 参数多 | 大扰动场景 |

## 思考题

1. 为什么四旋翼的姿态控制通常采用角速率环+角度环的级联结构，而不是单环控制？
2. 带宽分离原则中，为什么要求相邻环路带宽比至少 5-10 倍？如果比值太小会有什么问题？
3. 在四旋翼控制中，前馈解耦的作用是什么？请举例说明何时需要解耦。
4. PX4 飞控的级联 PID 参数调整顺序是什么？为什么？
5. 混合级联控制（如 MPC+PID）相比纯 PID 级联有什么优势？

<details>
<summary>参考答案</summary>

1. 级联结构优势：(1) 内环（角速率环）带宽高，能快速抑制扰动和模型不确定性；(2) 外环（角度环）可将内环视为"理想执行器"，简化设计；(3) 便于参数整定，先调内环再调外环；(4) 工程经验丰富，便于故障诊断。

2. 带宽比要求原因：(1) 如果比值太小，内外环动态耦合，难以独立设计；(2) 外环设计时假设内环为"理想执行器"，需要内环带宽足够高；(3) 比值过小时，外环控制器可能激发内环动态，导致振荡；(4) 通常 5-10 倍可保证内外环近似解耦。

3. 前馈解耦作用：消除通道间耦合，使各通道独立控制。例如：(1) 滚转和俯仰通道耦合较小，通常不需要解耦；(2) 偏航通道与滚转/俯仰有陀螺耦合，高速飞行时需要前馈补偿；(3) 位置环中，前馈可补偿重力分量。

4. PX4 调参顺序：(1) 先调 MC_ROLLRATE_P/I/D（角速率环）；(2) 再调 MC_ROLL_P/PITCH_P（角度环）；(3) 然后调 MPC_XY_VEL_P/I（速度环）；(4) 最后调 MPC_XY_P（位置环）。原因：从内到外，确保每层稳定后再设计外层。

5. MPC+PID 优势：(1) 外环 MPC 可显式处理约束（如最大倾斜角、最大速度）；(2) MPC 可优化轨迹，减少能量消耗；(3) 内环 PID 保持快速响应和简单性；(4) 适合约束严格的场景（如室内飞行、避障）。

</details>
