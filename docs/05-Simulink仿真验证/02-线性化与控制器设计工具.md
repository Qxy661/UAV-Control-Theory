## 1. 线性化概述

线性化是将非线性系统在工作点附近近似为线性系统的过程，是使用线性控制方法的基础。

### 1.1 线性化的意义

```
┌─────────────────────────────────────────────────┐
│              线性化的意义                         │
├─────────────────────────────────────────────────┤
│                                                 │
│  非线性系统：                                    │
│  ẋ = f(x, u)                                    │
│                                                 │
│  工作点线性化：                                   │
│  ẋ = A(x - x₀) + B(u - u₀)                     │
│                                                 │
│  其中：                                          │
│  A = ∂f/∂x |_{x₀,u₀}                           │
│  B = ∂f/∂u |_{x₀,u₀}                           │
│                                                 │
│  应用：                                          │
│  ├── LQR 控制器设计                             │
│  ├── 频域分析                                   │
│  ├── 鲁棒控制设计                               │
│  └── 稳定性分析                                 │
│                                                 │
└─────────────────────────────────────────────────┘
```

### 1.2 Simulink 线性化方法

| 方法 | 函数 | 适用场景 |
|------|------|---------|
| 模型线性化 | `linearize` | 整个模型 |
| 微扰法 | `linmod` | 简单模型 |
| 手动线性化 | 符号计算 | 解析分析 |

## 2. Simulink 线性化

### 2.1 基本线性化

```matlab
% Simulink 模型线性化
model_name = 'quadrotor_model';

% 1. 打开模型
open_system(model_name);

% 2. 设置线性化输入输出点
% 输入点
io(1) = linio([model_name '/Thrust'], 1, 'input');

% 输出点
io(2) = linio([model_name '/Position'], 1, 'output');

% 3. 设置工作点
op = operpoint(model_name);

% 4. 线性化
sys_linear = linearize(model_name, io, op);

% 5. 查看结果
size(sys_linear)
```

### 2.2 工作点设置

```matlab
% 设置工作点
% 方法1：使用 operpoint
op = operpoint(model_name);

% 方法2：手动设置
op.Inputs(1).u = 0.5;  % 输入值
op.States(1).x = [0; 0; 0];  % 状态值

% 方法3：使用 findop 求解工作点
op_spec = operspec(model_name);
op_spec.States(1).x = [0; 0; 0];
op_spec.Inputs(1).u = 0.5;
op = findop(model_name, op_spec);
```

### 2.3 线性化验证

```matlab
% 验证线性化结果
% 1. 比较阶跃响应
t = 0:0.01:5;

% 非线性仿真
[y_nonlinear, t] = sim(model_name, t);

% 线性系统响应
[y_linear, t] = step(sys_linear, t);

% 绘图对比
figure;
plot(t, y_nonlinear, 'b', t, y_linear, 'r--');
legend('非线性', '线性');
title('线性化验证');
xlabel('时间 (s)');
ylabel('输出');
```

## 3. SISO 设计工具

### 3.1 sisotool 使用

```matlab
% 打开 SISO 设计工具
sisotool(sys_linear);

% 或
sisotool('bode', sys_linear);
```

**sisotool 功能**：
- Bode 图设计
- 根轨迹设计
- Nichols 图
- 闭环响应

### 3.2 控制器设计流程

```
sisotool 设计流程：

1. 打开 sisotool，加载被控对象
2. 查看开环 Bode 图
3. 添加控制器（PID、超前滞后等）
4. 调整控制器参数
5. 查看闭环响应
6. 检查稳定裕度
7. 导出控制器
```

### 3.3 MATLAB 代码实现

```matlab
% 使用 sisotool 设计控制器
% 1. 打开工具
sisotool(sys_linear);

% 2. 设计完成后导出
% 在工具中点击 File > Export
% 或使用代码获取控制器
C = getCompensator(sisotool_handle);

% 3. 验证设计
L = C * sys_linear;  % 开环传递函数
margin(L);  % 查看稳定裕度
```

## 5. 频率响应估计

### 5.1 从 Simulink 模型估计

```matlab
% 从 Simulink 模型估计频率响应
% 使用频率响应估计器

% 1. 配置输入信号
% 使用正弦扫频信号
frequencies = logspace(-1, 2, 100);  % 0.1 到 100 rad/s

% 2. 仿真
for i = 1:length(frequencies)
    omega = frequencies(i);
    sim(model_name, [0 10/omega]);
    % 记录稳态幅值和相位
end

% 3. 绘制 Bode 图
```

### 5.2 使用频率响应估计器

```matlab
% 使用 frestimate 函数
% 1. 定义输入信号
input = frest.Sinestream('frequencies', frequencies);

% 2. 估计频率响应
sysest = frestimate(model_name, io, input);

% 3. 绘制结果
bode(sysest);
title('频率响应估计');
```

### 5.3 频率响应验证

```matlab
% 验证频率响应
% 1. 比较线性化和估计结果
sys_linear = linearize(model_name, io);
sysest = frestimate(model_name, io, input);

% 2. 绘图对比
figure;
bode(sys_linear, 'b', sysest, 'r--');
legend('线性化', '频率响应估计');
title('频率响应对比');
```

## 思考题

1. 为什么需要对非线性系统进行线性化？线性化的局限性是什么？
2. sisotool 和 Control System Designer 各有什么优势？
3. 如何验证线性化模型的准确性？
4. 频率响应估计与解析线性化有什么区别？
5. 在四旋翼控制设计中，通常在哪些工作点进行线性化？

<details>
<summary>参考答案</summary>

1. 线性化意义：(1) 使用线性控制方法（LQR、H-infinity）；(2) 频域分析和设计；(3) 稳定性分析。局限性：(1) 仅在工作点附近有效；(2) 大偏差时精度下降；(3) 不能反映全局非线性特性。

2. 工具优势：(1) sisotool：简单直观，适合 SISO 系统快速设计；(2) Control System Designer：功能全面，支持 MIMO，适合复杂设计。

3. 验证方法：(1) 比较阶跃响应；(2) 比较频率响应；(3) 检查极点位置；(4) 在不同偏差下验证。

4. 区别：(1) 解析线性化：基于数学推导，精度高但需要模型；(2) 频率响应估计：基于仿真数据，不需要显式模型；(3) 两者可相互验证。

5. 工作点选择：(1) 悬停点：最常用，大部分时间在此状态；(2) 巡航点：前飞状态；(3) 极限状态：最大速度、最大倾斜角；(4) 多个工作点：用于增益调度。

</details>
