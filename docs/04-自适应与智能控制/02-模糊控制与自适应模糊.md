## 1. 模糊控制概述

模糊控制（Fuzzy Control）是一种基于模糊逻辑的控制方法，利用专家知识和经验规则进行控制决策。

### 1.1 核心思想

```
┌─────────────────────────────────────────────────┐
│              模糊控制核心思想                      │
├─────────────────────────────────────────────────┤
│                                                 │
│  传统控制：                                      │
│  ├── 精确数学模型                                │
│  ├── 精确输入输出                                │

│                                                 │
```

## 2. 模糊控制器设计

### 2.1 模糊化

**隶属度函数**：

```matlab
function mu = triangular_mf(x, a, b, c)
    % 三角隶属度函数
    if x <= a || x >= c
        mu = 0;
    elseif x <= b
        mu = (x - a) / (b - a);
    else
        mu = (c - x) / (c - b);
    end
end

function mu = gaussian_mf(x, mean, sigma)
    % 高斯隶属度函数
    mu = exp(-(x - mean)^2 / (2 * sigma^2));
end
```

### 2.2 模糊规则库

**规则形式**：IF-THEN 规则

```
规则示例（PID 模糊控制）：
IF e is PB AND ec is NB THEN ΔKp is NB
IF e is PS AND ec is ZO THEN ΔKp is ZO
IF e is ZO AND ec is PS THEN ΔKp is PS
...
```

**语言变量**：
- NB: 负大 (Negative Big)
- NM: 负中 (Negative Medium)
- NS: 负小 (Negative Small)
- ZO: 零 (Zero)
- PS: 正小 (Positive Small)
- PM: 正中 (Positive Medium)
- PB: 正大 (Positive Big)

### 2.3 模糊推理

**Mamdani 推理**：

```matlab
function [output] = mamdani_inference(e, ec, rules, mf_params)
    % Mamdani 模糊推理
    % e, ec: 输入
    % rules: 规则库
    % mf_params: 隶属度函数参数

    % 模糊化
    mu_e = fuzzify(e, mf_params.e);
    mu_ec = fuzzify(ec, mf_params.ec);

    % 规则推理
    N = size(rules, 1);
    firing_strengths = zeros(N, 1);
    output_mf = zeros(N, 1);

    for i = 1:N
        % 规则前件的隶属度
        firing_strengths(i) = min(mu_e(rules(i,1)), mu_ec(rules(i,2)));

        % 规则后件
        output_mf(i) = firing_strengths(i) * rules(i, 3);
    end

    % 去模糊化（重心法）
    output = sum(output_mf) / sum(firing_strengths);
end
```

### 2.4 去模糊化

**重心法**：

$$u = \frac{\sum_{i=1}^{N} w_i \cdot c_i}{\sum_{i=1}^{N} w_i}$$

```matlab
function u = defuzzification(w, c, method)
    % 去模糊化
    switch method
        case 'centroid'
            u = sum(w .* c) / sum(w);
        case 'mean_of_max'
            max_w = max(w);
            u = mean(c(w == max_w));
        case 'smallest_of_max'
            max_w = max(w);
            u = min(c(w == max_w));
    end
end
```

## 3. 自适应模糊控制

### 3.1 自适应模糊控制原理

**问题**：模糊规则需要专家知识，可能不完善

**解决**：在线调整模糊规则或隶属度函数

```
┌─────────────────────────────────────────────────┐
│              自适应模糊控制                        │
├─────────────────────────────────────────────────┤
│                                                 │
│  r(t) ──→ [模糊控制器] ──→ u ──→ [被控对象] ──→ y
│              ↑                        │         │
│              │                        │         │
│              └────────────────────────┘         │
│                         ↑                        │
│                    [自适应律]                     │
│                    在线调整规则                    │
│                                                 │
│  自适应方法：                                    │
│  ├── 调整规则后件                                │
│  ├── 调整隶属度函数                              │
│  └── 调整规则权重                                │
│                                                 │
└─────────────────────────────────────────────────┘
```

### 3.2 Lyapunov 自适应模糊控制

**系统**：$\dot{x} = f(x) + bu + d$

**模糊逼近**：$f(x) = \theta^T \phi(x) + \epsilon$

**控制律**：

$$u = \frac{1}{b}(-\hat{\theta}^T \phi(x) - cx - k \cdot \text{sign}(s))$$

**自适应律**：

$$\dot{\hat{\theta}} = \Gamma \phi(x) s$$

### 3.3 MATLAB 实现

```matlab
function [u, theta_hat] = adaptive_fuzzy_control(x, x_d, x_dot_d, ...
    theta_hat, fuzzy_params, control_params)
    % 自适应模糊控制

    % 参数
    c = control_params.c;
    k = control_params.k;
    b = control_params.b;
    Gamma = control_params.Gamma;

    % 模糊系统输出
    phi = fuzzy_basis(x, fuzzy_params);
    f_hat = theta_hat' * phi;

    % 误差
    e = x - x_d;
    s = e + c * integral_e;

    % 控制律
    u = (1/b) * (-f_hat - c*e - k*sign(s) + x_dot_d);

    % 自适应律
    theta_hat_dot = Gamma * phi * s;
    theta_hat = theta_hat + theta_hat_dot * dt;
end

function phi = fuzzy_basis(x, params)
    % 模糊基函数
    N = params.N;  % 规则数
    centers = params.centers;
    widths = params.widths;

    phi = zeros(N, 1);
    for i = 1:N
        phi(i) = exp(-norm(x - centers(:,i))^2 / (2*widths(i)^2));
    end
    phi = phi / sum(phi);  % 归一化
end
```

## 5. 模糊控制在无人机中的应用

### 5.1 模糊 PID 控制

```matlab
function [Kp, Ki, Kd] = fuzzy_PID_tuning(e, ec, rules)
    % 模糊 PID 调参
    % e: 误差
    % ec: 误差变化率
    % rules: 模糊规则

    % 模糊推理
    delta_Kp = fuzzy_inference(e, ec, rules.Kp);
    delta_Ki = fuzzy_inference(e, ec, rules.Ki);
    delta_Kd = fuzzy_inference(e, ec, rules.Kd);

    % 更新 PID 参数
    Kp = Kp0 + delta_Kp;
    Ki = Ki0 + delta_Ki;
    Kd = Kd0 + delta_Kd;
end
```

## 思考题

1. 模糊控制的"隶属度函数"有什么物理意义？
2. Mamdani 推理和 Takagi-Sugeno 推理有什么区别？
3. 自适应模糊控制如何在线调整规则？
4. Type-2 模糊控制相比 Type-1 有什么优势？
5. 在四旋翼控制中，模糊控制主要用于什么场景？

<details>
<summary>参考答案</summary>

1. 隶属度函数物理意义：(1) 表示输入属于某个模糊集的程度；(2) 值域 [0,1]，0 表示完全不属于，1 表示完全属于；(3) 实现精确量到模糊量的转换；(4) 不同形状（三角、高斯）表示不同偏好。

2. 推理方法区别：(1) Mamdani：后件是模糊集，需要去模糊化；(2) T-S：后件是函数，输出是加权平均；(3) T-S 计算更简单，适合分析；(4) Mamdani 更直观，便于专家知识表达。

3. 在线调整：(1) 调整规则后件的参数；(2) 使用 Lyapunov 方法设计自适应律；(3) 例如：θ̇ = Γφ(x)s；(4) 保证稳定性的同时改善性能。

4. Type-2 优势：(1) 处理隶属度函数本身的不确定性；(2) 对噪声和扰动更鲁棒；(3) 适合专家知识不确定的场景；(4) 缺点：计算复杂度高。

5. 应用场景：(1) 模糊 PID 调参；(2) 模式切换逻辑；(3) 故障诊断和容错；(4) 专家知识集成。

</details>
