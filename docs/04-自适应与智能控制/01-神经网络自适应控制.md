## 1. 神经网络控制概述

神经网络（Neural Network, NN）在控制中的应用主要是利用其强大的函数逼近能力来估计系统中的未知非线性函数。

### 1.1 核心思想

```
┌─────────────────────────────────────────────────┐
│              神经网络控制核心思想                   │
├─────────────────────────────────────────────────┤
│                                                 │
│  问题：系统存在未知非线性 f(x)                    │
│  ẋ = f(x) + g(x)u + d                          │
│                                                 │
│  解决：用神经网络逼近 f(x)                        │
│  f̂(x) = W^T σ(V^T x)                           │
│                                                 │
│  控制律：                                        │
│  u = -f̂(x)/ĝ(x) + 控制补偿                     │
│                                                 │
│  优点：                                          │
│  ├── 通用逼近能力                                │
│  ├── 在线学习                                   │
│  └── 不需要精确模型                              │
│                                                 │
└─────────────────────────────────────────────────┘
```

### 1.2 神经网络类型

| 类型 | 特点 | 适用场景 |
|------|------|---------|
| RBF NN | 局部逼近，收敛快 | 在线学习 |

## 2. RBF 神经网络

### 2.1 RBF 网络结构

**径向基函数（RBF）网络**：

$$f_{NN}(x) = \sum_{i=1}^{N} w_i \phi_i(x) = W^T \Phi(x)$$

其中：
- $W = [w_1, w_2, ..., w_N]^T$：权值向量
- $\Phi(x) = [\phi_1(x), \phi_2(x), ..., \phi_N(x)]^T$：基函数向量
- $\phi_i(x) = \exp\left(-\frac{||x - c_i||^2}{2\sigma_i^2}\right)$：高斯基函数

### 2.2 MATLAB 实现

```matlab
function [f_nn, Phi] = RBF_NN(x, W, centers, widths)
    % RBF 神经网络
    % x: 输入
    % W: 权值
    % centers: 中心点
    % widths: 宽度

    N = size(centers, 2);  % 隐层节点数
    Phi = zeros(N, 1);

    for i = 1:N
        Phi(i) = exp(-norm(x - centers(:,i))^2 / (2*widths(i)^2));
    end

    f_nn = W' * Phi;
end
```

### 2.3 万能逼近定理

**定理**：对于任意连续函数 $f(x)$ 和任意 $\epsilon > 0$，存在 RBF 网络使得：

$$\sup_{x \in \Omega} |f(x) - W^{*T} \Phi(x)| < \epsilon$$

其中 $W^*$ 为最优权值。

## 3. 基于 Lyapunov 的 NN 控制

### 3.1 控制器设计

**系统**：$\dot{x} = f(x) + bu + d$

**NN 逼近**：$f(x) = W^{*T} \Phi(x) + \epsilon$

**控制律**：

$$u = \frac{1}{b}(-\hat{W}^T \Phi(x) - cx - k \cdot \text{sign}(s) + \dot{x}_d)$$

**权值更新律**：

$$\dot{\hat{W}} = \Gamma \Phi(x) s$$

### 3.2 Lyapunov 稳定性分析

**Lyapunov 函数**：

$$V = \frac{1}{2} s^2 + \frac{1}{2} \tilde{W}^T \Gamma^{-1} \tilde{W}$$

其中 $\tilde{W} = \hat{W} - W^*$

**导数**：

$$\dot{V} = s \dot{s} + \tilde{W}^T \Gamma^{-1} \dot{\tilde{W}}$$

代入 $\dot{s} = -cs - k \cdot \text{sign}(s) - \tilde{W}^T \Phi(x) + \epsilon$（其中 $\tilde{W}^T \Phi$ 为 NN 逼近误差项）：

$$\dot{V} = s[-cs - k \cdot \text{sign}(s) - \tilde{W}^T \Phi(x) + \epsilon] + \tilde{W}^T \Gamma^{-1} \dot{\tilde{W}}$$

展开：

$$\dot{V} = -cs^2 - k|s| + \epsilon s - \tilde{W}^T \Phi(x) s + \tilde{W}^T \Gamma^{-1} \dot{\tilde{W}}$$

代入权值更新律 $\dot{\hat{W}} = \Gamma \Phi(x) s$，注意到 $\dot{\tilde{W}} = \dot{\hat{W}}$（真值 $W^*$ 为常数）：

$$\tilde{W}^T \Gamma^{-1} \dot{\tilde{W}} = \tilde{W}^T \Gamma^{-1} \Gamma \Phi(x) s = \tilde{W}^T \Phi(x) s$$

**交叉项抵消**：$-\tilde{W}^T \Phi(x) s$ 与 $+\tilde{W}^T \Phi(x) s$ 相消，因此：

$$\dot{V} = -cs^2 - k|s| + \epsilon s \leq 0$$

当 $k \geq |\epsilon|_{\max}$ 时，$\dot{V} \leq -cs^2 \leq 0$，系统渐近稳定。

### 3.3 MATLAB 实现

```matlab
function [u, W_hat] = NN_adaptive_control(x, x_d, x_dot_d, W_hat, ...
    centers, widths, b, c, k, Gamma, dt, integral_e)
    % 神经网络自适应控制
    % integral_e: 误差的积分项 ∫e dt，用于构造滑模面 s = e + c*integral_e

    % 计算 RBF 基函数
    [~, Phi] = RBF_NN(x, W_hat, centers, widths);

    % 误差
    e = x - x_d;
    s = e + c * integral_e;  % 滑模面

    % 控制律
    u = (1/b) * (-W_hat' * Phi - c*e - k*sign(s) + x_dot_d);

    % 权值更新
    W_hat_dot = Gamma * Phi * s;
    W_hat = W_hat + W_hat_dot * dt;
end
```

## 4. NN 在无人机中的应用

### 4.1 姿态 NN 自适应控制

```matlab
function [tau, W_hat] = attitude_NN_control(phi, theta, psi, p, q, r, ...
    phi_ref, theta_ref, psi_ref, W_hat, params)
    % 四旋翼姿态 NN 自适应控制

    % 误差
    e_phi = phi - phi_ref;
    e_theta = theta - theta_ref;
    e_psi = psi - psi_ref;

    % RBF NN 逼近不确定性
    x_nn = [phi; theta; psi; p; q; r];
    [f_nn, Phi] = RBF_NN(x_nn, W_hat, params.centers, params.widths);

    % 控制律
    tau = -f_nn - params.k * [e_phi; e_theta; e_psi];

    % 权值更新
    W_hat_dot = params.Gamma * Phi * [e_phi; e_theta; e_psi]';
    W_hat = W_hat + W_hat_dot * params.dt;
end
```

## 5. NN 控制的改进

### 5.1 死区修正

**问题**：小误差时权值振荡

**解决**：引入死区

```matlab
function W_hat = deadzone_update(W_hat, Phi, s, Gamma, delta)
    % 死区修正
    if abs(s) > delta
        W_hat_dot = Gamma * Phi * s;
    else
        W_hat_dot = 0;
    end
    W_hat = W_hat + W_hat_dot * dt;
end
```

### 5.2 σ-修正

**问题**：权值漂移

**解决**：σ-修正

```matlab
function W_hat = sigma_modification(W_hat, Phi, s, Gamma, sigma)
    % σ-修正
    W_hat_dot = Gamma * (Phi * s - sigma * W_hat);
    W_hat = W_hat + W_hat_dot * dt;
end
```

## 思考题

1. RBF 神经网络为什么适合在线学习控制？
2. 如何选择 RBF 网络的中心点和宽度？
3. NN 控制的 Lyapunov 稳定性分析中，逼近误差 ε 有什么影响？
4. σ-修正和死区修正各解决什么问题？
5. 在四旋翼控制中，NN 主要用于逼近什么？

<details>
<summary>参考答案</summary>

1. RBF 适合在线学习：(1) 局部逼近，收敛快；(2) 结构简单，计算量小；(3) 万能逼近定理保证；(4) 权值更新有明确的 Lyapunov 稳定性保证。

2. 选择方法：(1) 中心点：均匀分布在输入空间，或使用聚类算法；(2) 宽度：根据输入范围选择，通常 σ ≈ 0.5-2.0；(3) 节点数：根据逼近精度要求，通常 10-100。

3. 逼近误差影响：(1) ε 存在时，系统最终收敛到包含 ε 的邻域；(2) 增大节点数可减小 ε；(3) 鲁棒项可抑制 ε 的影响。

4. 修正方法：(1) σ-修正：防止权值漂移，但有稳态误差；(2) 死区修正：避免小误差时权值振荡；(3) 两者可结合使用。

5. NN 逼近对象：(1) 气动不确定性（阻力、升力变化）；(2) 参数不确定性（质量、惯量）；(3) 外部扰动（风扰动）；(4) 耦合项（通道间耦合）。

</details>
