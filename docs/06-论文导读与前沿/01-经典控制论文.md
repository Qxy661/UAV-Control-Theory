```
## 论文卡片：Ziegler-Nichols PID Tuning

**基本信息**
- 作者：J.G. Ziegler, N.B. Nichols
- 发表：Transactions of the ASME
- 年份：1942

**核心贡献**
- 解决的问题：PID 参数整定缺乏系统方法

**实验结果**
- 适用范围广
- 简单易用
- 但可能过于激进

**个人评价**
- 优点：简单、快速、广泛适用
- 缺点：超调较大、需要现场测试
- 启发：经验方法的系统化
```

### 3.2 论文卡片：四旋翼 LQR 控制

```
## 论文卡片：LQR Control of Quadrotor UAV

**基本信息**
- 作者：P. Pounds et al.
- 发表：Australasian Conference on Robotics and Automation
- 年份：2012

**核心贡献**
- 解决的问题：四旋翼姿态控制
- 提出的方法：LQR 姿态控制器
- 主要创新：系统化的 LQR 设计流程

**方法细节**
- 系统模型：6-DOF 刚体动力学
- 线性化：悬停点线性化
- LQR 设计：Q、R 矩阵选择

**关键方程 — LQR 代价函数**

$$
J = \int_0^{\infty} \left( x^T Q x + u^T R u \right) dt
$$

其中 $Q \succeq 0$ 为状态权重矩阵，$R \succ 0$ 为控制权重矩阵。最优控制律为 $u = -Kx$，其中 $K = R^{-1}B^T P$，$P$ 为代数 Riccati 方程 $A^TP + PA - PBR^{-1}B^TP + Q = 0$ 的正定解。

**实验结果**
- 仿真验证良好
- 实际飞行测试成功
- 优于手动调参 PID

**个人评价**
- 优点：系统化设计、性能可预测
- 缺点：需要精确模型
- 启发：LQR 作为 PID 的替代方案
```

### 5.2 论文卡片：H-infinity 飞行控制

```
## 论文卡片：H-infinity Flight Control

**基本信息**
- 作者：G. Papageorgiou et al.
- 发表：AIAA Guidance, Navigation and Control Conference
- 年份：2006

**核心贡献**
- 解决的问题：飞行器鲁棒控制
- 提出的方法：H-infinity 控制器
- 主要创新：系统化的鲁棒设计流程

**方法细节**
- 不确定性建模：参数变化、未建模动态
- 权重函数选择
- 控制器综合

**关键方程 — H-infinity 性能指标**

$$
\| T_{zw} \|_{\infty} = \sup_{\omega} \bar{\sigma}\left[ T_{zw}(j\omega) \right]
$$

其中 $T_{zw}(j\omega)$ 为从扰动 $w$ 到性能输出 $z$ 的闭环传递函数，$\bar{\sigma}(\cdot)$ 表示最大奇异值。设计目标为 $\| T_{zw} \|_{\infty} < \gamma$，即在所有频率上将扰动增益抑制在 $\gamma$ 以下。

**实验结果**
- 仿真验证良好
- 对参数变化鲁棒
- 满足 MIL-STD 规范

**个人评价**
- 优点：理论保证、鲁棒性强
- 缺点：保守、设计复杂
- 启发：鲁棒控制的工程应用
```

## 思考题

1. 为什么 Ziegler-Nichols 方法至今仍被广泛使用？
2. LQR 控制相比 PID 在无人机控制中有什么优势？
3. 如何评价一篇控制论文的创新性？
4. 级联控制为什么是无人机飞控的主流架构？
5. 如何将论文中的方法应用到自己的项目中？

<details>
<summary>参考答案</summary>

1. ZN 方法广泛使用原因：(1) 简单易懂，无需复杂数学；(2) 适用范围广；(3) 有明确步骤；(4) 工程经验丰富；(5) 作为初始调参的良好起点。

2. LQR 优势：(1) 系统化设计，有理论保证；(2) 可处理 MIMO 系统；(3) 性能指标明确；(4) 可预测闭环性能。

3. 创新性评价：(1) 解决新问题或老问题新方法；(2) 理论贡献或工程创新；(3) 实验验证充分；(4) 与现有方法对比明确。

4. 级联控制主流原因：(1) 工程经验丰富；(2) 便于调参和调试；(3) 带宽分离简化设计；(4) 便于故障诊断；(5) 适用于嵌入式实现。

5. 应用方法：(1) 理解核心思想；(2) 复现关键结果；(3) 根据自己系统调整；(4) 逐步集成到项目。
