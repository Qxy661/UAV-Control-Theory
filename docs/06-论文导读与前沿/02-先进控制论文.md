### 1.2 论文卡片：ADRC 在四旋翼中的应用

```
## 论文卡片：ADRC for Quadrotor Control

**基本信息**
- 作者：S. Li et al.
- 发表：ISA Transactions
- 年份：2018

**核心贡献**
- 解决的问题：四旋翼姿态控制中的扰动问题
- 提出的方法：级联 ADRC 姿态控制
- 主要创新：ESO 估计总扰动并补偿

**方法细节**
- 系统模型：考虑气动扰动和模型不确定性
- ESO 设计：估计状态和总扰动
- 控制律：反馈线性化 + 扰动补偿

**实验结果**
- 仿真：风扰动抑制效果好
- 实际：比 PID 更好的抗扰性能

**个人评价**
- 优点：不依赖精确模型、抗扰能力强
- 缺点：参数较多、需要调参
- 启发：ADRC 是 PID 的有力替代
```

### 2.2 论文卡片：MRAC 四旋翼控制

```
## 论文卡片：MRAC for Quadrotor with Uncertainties

**基本信息**
- 作者：T. Lee et al.
- 发表：IEEE Trans. on Control Systems Technology
- 年份：2016

**核心贡献**
- 解决的问题：四旋翼参数不确定性
- 提出的方法：Lyapunov-based MRAC
- 主要创新：自适应律保证稳定性

**方法细节**
- 参考模型：期望的闭环性能
- 自适应律：基于 Lyapunov 方法
- 鲁棒修正：σ-修正防止参数漂移

**实验结果**
- 参数变化 ±30% 仍能稳定
- 跟踪误差小
- 优于固定增益 PID

**个人评价**
- 优点：自适应能力强、稳定性保证
- 缺点：需要持续激励、设计复杂
- 启发：自适应控制的实际应用
```

```
## 论文卡片：Backstepping Control for UAV Attitude

**基本信息**
- 作者：A. Das et al.
- 发表：AIAA Guidance, Navigation and Control Conference
- 年份：2009

**核心贡献**
- 解决的问题：四旋翼姿态非线性控制
- 提出的方法：Backstepping 姿态控制器
- 主要创新：递归设计处理非线性

**方法细节**
- 系统模型：完整非线性姿态动力学

**实验结果**
- 大角度机动性能好
- 比线性方法更鲁棒
- 实时计算可行

**个人评价**
- 优点：理论严格、全局稳定
- 缺点：需要精确模型、设计复杂
- 启发：非线性控制的实用方法
```

## 思考题

1. ADRC 和 MRAC 在处理不确定性方面有什么本质区别？
2. Backstepping 和滑模控制各有什么优势？如何选择？
3. 如何评价一篇先进控制论文的实用价值？
4. 非线性控制方法相比线性方法，在四旋翼控制中有什么优势？
5. 如何将论文中的方法转化为可运行的代码？

<details>
<summary>参考答案</summary>

1. 区别：(1) ADRC：通过 ESO 估计总扰动并补偿，不需要模型；(2) MRAC：通过调整控制器参数跟踪参考模型，需要参考模型；(3) ADRC 更适合扰动大的场景，MRAC 更适合参数变化的场景。

2. 选择依据：(1) Backstepping：需要严格反馈形式，理论严格，全局稳定；(2) 滑模控制：对不确定性鲁棒，有抖振问题；(3) 选择：模型精确用 Backstepping，不确定性大用滑模。

3. 实用价值：(1) 是否有实验验证；(2) 计算复杂度是否可接受；(3) 参数整定是否方便；(4) 与现有方法对比是否明显优势。

4. 非线性方法优势：(1) 大角度机动性能好；(2) 对非线性特性处理更准确；(3) 不需要线性化假设；(4) 可能有更好的鲁棒性。

5. 代码转化：(1) 理解算法核心思想；(2) 从简单系统开始实现；(3) 逐步增加复杂度；(4) 与仿真结果对比验证。

</details>
