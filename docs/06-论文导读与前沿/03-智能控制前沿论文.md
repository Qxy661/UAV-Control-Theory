### 1.2 论文卡片：NN 自适应四旋翼控制

```
## 论文卡片：Neural Network Adaptive Control for Quadrotor

**基本信息**
- 作者：T. Dierks et al.
- 发表：IEEE Trans. on Neural Networks
- 年份：2010

**核心贡献**
- 解决的问题：四旋翼非线性不确定性
- 提出的方法：NN 自适应控制
- 主要创新：在线学习逼近不确定性

**方法细节**
- NN 结构：RBF 网络
- 逼近对象：未知非线性函数
- 自适应律：基于 Lyapunov 方法
- 稳定性：闭环系统渐近稳定

**实验结果**
- 逼近误差小
- 跟踪性能好
- 优于固定增益控制

**个人评价**
- 优点：自适应能力强
- 缺点：需要持续激励
- 启发：NN 在实际控制中的应用
```

### 2.2 论文卡片：模糊 PID 四旋翼控制

```
## 论文卡片：Fuzzy PID Control for Quadrotor

**基本信息**
- 作者：A. Zeghloul et al.
- 发表：ISA Transactions
- 年份：2017

**核心贡献**
- 解决的问题：PID 参数在线调整
- 提出的方法：模糊 PID 控制
- 主要创新：利用专家知识调整 PID

**方法细节**
- 模糊规则：基于专家经验
- 输入：误差和误差变化率
- 输出：PID 参数调整量
- 去模糊化：重心法

**实验结果**
- 优于固定 PID
- 适应性好
- 实时性可接受

**个人评价**
- 优点：简单、实用
- 缺点：规则依赖专家
- 启发：传统与智能方法结合
```

**基本信息**
- 作者：J. Hwangbo et al.

- 鲁棒性强

- 优点：自动学习最优策略
- 缺点：训练成本高

## 思考题

1. 强化学习控制相比传统控制有什么优势和劣势？
2. 神经网络控制的可解释性问题如何解决？
3. Sim-to-Real 迁移的主要挑战是什么？
4. 安全学习控制为什么重要？有哪些方法？
5. 混合智能控制相比单一方法有什么优势？

<details>
<summary>参考答案</summary>

1. RL 优势：(1) 不需要精确模型；(2) 自动优化策略；(3) 可处理复杂非线性。劣势：(1) 样本效率低；(2) 安全性难保证；(3) 可解释性差。

2. 可解释性解决：(1) 使用可解释的 NN 结构（如 RBF）；(2) 结合传统控制理论；(3) 形式化验证；(4) 可视化分析。

3. Sim-to-Real 挑战：(1) 仿真与真实环境差异；(2) 传感器噪声和延迟；(3) 物理参数不确定性。解决：域随机化、系统辨识、渐进迁移。

4. 安全 RL 重要性：(1) 无人机坠毁成本高；(2) 训练过程需安全；(3) 方法：CBF、安全层、约束 RL。

5. 混合方法优势：(1) 各方法优势互补；(2) 提高鲁棒性；(3) 改善性能；(4) 降低设计难度。

</details>
